# 修复 Anki 导入页面底部溢出与路径输入对话框崩溃

## Goal
修复 `lib/views/anki/anki_import_screen.dart` 中的两个连续缺陷：

1. **布局溢出**：在"导入 Anki 牌组"页面，弹出"输入文件路径"对话框、软键盘弹起后，底层页面（`_buildSelectStep`）底部溢出 158 px（BOTTOM OVERFLOWED BY 158 PIXELS），位于"打开示例牌组"按钮附近。
2. **运行时崩溃**：在"输入文件路径"对话框中点击"取消"或"导入此文件"，应用立即闪退，控制台输出 Flutter 框架断言 `package:flutter/src/widgets/framework.dart': Failed assertion: line 6171 pos 14: '_dependents.isEmpty': is not true.`

## Scope / Non-goals
- 仅修改 `lib/views/anki/anki_import_screen.dart` 一个文件。
- 不修改其它页面的 TextEditingController 用法（已经是标准 State 字段模式，没有问题）。
- 不调整设计/视觉风格；仅做布局健壮性修复和生命周期正确性修复。

## Current State And Constraints

### 相关代码（`lib/views/anki/anki_import_screen.dart`）

**`_buildSelectStep()`（行 142-258）**：
当前结构是 `Center > Padding(32) > Column(mainAxisAlignment: center, default children)`，包含：
- 80 px 图标 + 24 px 间距
- 标题 + 12 px 间距
- 副标题
- 32 px 间距
- 可选错误文案
- 主"选择文件" ElevatedButton.icon
- OHos 分支：提示文字 + "扫描目录" OutlinedButton + "输入路径" TextButton
- 16 px 间距 + "打开示例牌组" OutlinedButton + 8 px + 提示文字

在 HarmonyOS 手机 + 软键盘（~屏幕高度一半）同时出现的场景下，整体内容高度大于剩余视口高度。`Center` 不会让内容滚动，`Column` 不收缩，结果底部 158 px 被裁切并触发 RenderFlex overflow。

**`_showPathInputDialog()`（行 667-709）**：

### 崩溃根因分析
Flutter 框架在 `Element.unmount()`（行 6171 附近）要求 `_dependents` 集合必须为空，否则会触发断言。`TextField` 内部依赖 `TextEditingController`（监听 `value`/`selection` 变化以重建光标与 IME 状态），并在 `EditableText.dispose` 中通过 `controller.removeListener(...)` 注销依赖。

异常顺序：
1. 用户点击"取消"或"导入此文件" → `Navigator.pop` 触发 `DialogRoute` 卸载。
2. 卸载过程中 `TextField`/`EditableText` 试图先卸载再 `removeListener`。但因为 controller 在 `_AnkiImportPageState` 的 builder 闭包里持有，**闭包作用域仍在栈上**，controller 仍然有效且 `_dependents` 尚未被清空。
3. 同一个动画帧内 `Element.unmount()` 在 `EditableText` 注销 listener 之前被断言命中 → `_dependents.isEmpty` 失败 → 进程被断言杀掉 → 红色全屏错误页。

正确做法是：让 `TextEditingController` 的生命周期与 `TextField`/`EditableText` 一致——由对话框自己的 `State.dispose()` 释放，永远不要在 `await showDialog(...)` 返回后再 `dispose`。

## Design

### 修复 1：底部溢出
把 `_buildSelectStep` 的根布局从 `Center > Padding > Column` 改为可滚动 + 自适应最小高度：

```dart
Widget _buildSelectStep() {
  return SafeArea(
    child: LayoutBuilder(
      builder: (context, constraints) => SingleChildScrollView(
        child: ConstrainedBox(
          constraints: BoxConstraints(minHeight: constraints.maxHeight),
          child: IntrinsicHeight(
            child: Padding(
              padding: const EdgeInsets.all(32),
              child: Column(
                mainAxisAlignment: MainAxisAlignment.center,
                children: [ /* …原 children… */ ],
              ),
            ),
          ),
        ),
      ),
    ),
  );
}
```

要点：
- `LayoutBuilder` + `ConstrainedBox(minHeight: maxHeight)` 让内容少时仍居中，多时可超出滚动。
- `IntrinsicHeight` 让 `Column(mainAxisAlignment: center)` 在 IntrinsicHeight 内生效。
- `SafeArea` 防止底部系统手势条遮挡最后一行（"样本" 提示文字）。
- 这样无论键盘是否弹起、内容是否增多，Column 都不会溢出。

### 修复 2：路径对话框崩溃
将对话框拆成独立的 `StatefulWidget`，由其 `State` 持有 controller 并在 `dispose()` 中释放。`showDialog` 的 builder 只负责构建。

```dart
class _AnkiPathInputDialog extends StatefulWidget {
  const _AnkiPathInputDialog();

  @override
  State<_AnkiPathInputDialog> createState() => _AnkiPathInputDialogState();
}

class _AnkiPathInputDialogState extends State<_AnkiPathInputDialog> {
  late final TextEditingController _controller;

  @override
  void initState() {
    super.initState();
    _controller = TextEditingController();
  }

  @override
  void dispose() {
    _controller.dispose();        // 与 TextField 的 unmount 同一动画帧前完成
    super.dispose();
  }

  @override
  Widget build(BuildContext context) {
    return AlertDialog(
      title: Text(AppStrings.ankiFallbackPathTitle),
      content: TextField(
        controller: _controller,
        autofocus: true,
        decoration: InputDecoration(
          labelText: AppStrings.ankiFallbackPathHint,
          hintText: AppStrings.ankiFallbackPathHint,
        ),
        maxLines: 3,
        minLines: 1,
      ),
      actions: [
        TextButton(
          onPressed: () => Navigator.of(context).pop(),
          child: const Text('取消'),
        ),
        ElevatedButton(
          onPressed: () => Navigator.of(context).pop(_controller.text),
          child: Text(AppStrings.ankiFallbackPathAction),
        ),
      ],
    );
  }
}
```

调用处简化为：
```dart
Future<void> _showPathInputDialog() async {
  if (!mounted) return;
  final path = await showDialog<String>(
    context: context,
    builder: (ctx) => const _AnkiPathInputDialog(),
  );
  final trimmed = path?.trim();
  if (trimmed == null || trimmed.isEmpty) return;
  try {
    await OhosFilePicker.importFromPath(
      path: trimmed,
      allowedExtensions: _ankiExtensions,
    );
    await _proceedWithPath(trimmed);
  } on PlatformException catch (e) {
    if (!mounted) return;
    setState(() => _error = '${AppStrings.ankiPickFileFailed(e.message ?? e.code)}');
  }
}
```

这样：
- `TextEditingController` 由 `_AnkiPathInputDialogState` 持有 → `dispose()` 由框架在 `Element.unmount` 阶段同步调用，先于 `_dependents` 断言。
- 不再需要外层 `controller.dispose()`，消除顺序竞争。
- 行为完全等价：取消 → `null` → return；确定 → 返回文本 → 走 `_proceedWithPath`。

## Risks And Compatibility
- `SafeArea` 会消耗底部安全区；在已有底部导航/手势条的真机上仍可滚动到所有按钮，无功能损失。
- `IntrinsicHeight` 在 `Column` 内容多时会进行 intrinsic pass，性能可忽略（本页面内容静态，渲染频率低）。
- 将 `TextEditingController` 改为 State 字段是 Flutter 标准模式，与项目其它文件一致（参见 `lib/views/lesson/components/interactions/*_renderer.dart` 等）。
- 不改动 public API、不改动 navigation/route 注入（`@RoutePage()` 注解保留）。
- HarmonyOS / Android / iOS 行为一致：`_dependents.isEmpty` 断言由 Flutter framework 在所有平台强制检查，本修复对所有平台生效。
