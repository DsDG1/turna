# 修复 Anki 删除残留 bug + 导入识别页傻瓜式简化

## Part A: 删除残留文件完整修复（bug 1）

**根因**：`AnkiImportCleanupService.deleteAll` 第 56 行用一次性 `Directory.deleteSync(recursive: true)` 删媒体目录，任何一个文件被 just_audio 播放器 / WebView 占用就整体抛异常中断 saga；此时课程树已删（牌组从界面消失、无重试入口），`anki_imports` 记录未删、目录部分残留。

### A1. 媒体目录改为逐文件 best-effort 删除
- `lib/domain/audio/anki_media_platform_io.dart`：新增 `ankiDeleteDirectoryBestEffort(String path)`，返回删除报告（成功数 + 残留路径列表）：逐文件删、单文件失败不中断、自底向上清空目录；同步更新 `anki_media_platform_stub.dart` 桩实现。原 `ankiDeleteDirectory` 保留给临时解压目录（`anki_importer.dart:340`）用。

### A2. `deleteImportMedia` 不再抛异常
- `lib/domain/audio/anki_audio_resolver.dart:101-106`：改返回删除报告，整体 try/catch 包裹，永不向上抛。

### A3. 释放播放器锁 + saga 不再中断
- `lib/application/audio_controller.dart`：新增公开方法 `Future<void> stopSpeechPlayer()`（现有 `stopSystemTts` 只停 TTS，持有媒体句柄的是 `_speechPlayer`）。
- `lib/application/anki/anki_import_cleanup_service.dart`：注入可选 `AudioController`（3 处构造点：`anki_deck_manager.dart:483`、`anki_import_screen.dart:1402/2143`）；`deleteAll` 中先停播放器再 best-effort 删媒体，失败记日志不中断，保证 `importDao.delete` 等后续步骤全部执行（残留目录因记录已删变为无主孤儿，由 A4 回收）。

### A4. 启动时自动清理孤儿媒体目录
- 新增清扫函数：列出 `anki_media/` 子目录，`importDao.getById(dirName) == null` 的目录 best-effort 删除（`getById` 已存在，`anki_deck_manager.dart:300` 在用）。
- 在 `main.dart` 约 :145（`retryPendingOfficialCleanups` 旁）调用，try/catch 包裹。

### A5. 存储诊断页增加残留删除入口
- `lib/application/maintenance/storage_inventory_service.dart`：新增按孤儿 artifact 删除目录的方法。
- `lib/views/settings/storage_diagnostics_page.dart` `_OrphanWarningCard`（:452）：加"删除残留文件"按钮 + 确认对话框，删除后刷新清单（覆盖历史遗留的各种卡死状态）。

### A6. 两个删除入口加错误提示
- `lib/views/courses/course_management_page.dart:237`、`lib/views/anki/anki_review_screen.dart:464`：try/catch + 失败 SnackBar，无论成败都刷新列表。

### A7. 测试
- 新增：best-effort 目录删除（含占用文件场景）、清理 saga 在媒体删除失败后仍完成、孤儿清扫判定逻辑。

## Part B: 导入识别页折叠式简化（需求 2）
