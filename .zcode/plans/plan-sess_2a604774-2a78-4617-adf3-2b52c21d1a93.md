# 字体调节显示效果优化 — 实施计划

按此前分析的 5 项优化全部落地。核心设计决策:**新增独立的"卡面文字大小"(`cardTextScale`)设置,默认 100%(不动卡面,保持保真约定),统一驱动两条卡片渲染轨道**;全局"文字大小"继续只管 Flutter 原生 UI。

## A. 新增 cardTextScale 设置(存储 + UI + 实时预览)

1. **`lib/service/locator.dart`** — `LocalStateKeys` 无障碍键组(约 L274-281)新增:
   `static const String cardTextScale = 'settings.cardTextScale';`(注释注明 int percent, 100=1.0)

2. **`lib/application/accessibility_provider.dart`** — 镜像 textScale 现有模式:
   - `int _cardTextScale = 100;` + getter;`_load()` 读 `LocalStateKeys.cardTextScale`(defaultValue 100);`reload()` 无需改(整体重读)
   - `setCardTextScale(int)`:`clamp(100, 200)` → `_cardTextScale` → `setInt` → `notifyListeners`(照抄 L83-88 的 setTextScale)
   - 新增 `void previewTextScale(int)` 与 `void previewCardTextScale(int)`:**只更新内存字段 + notifyListeners,不写 prefs**(实时预览用;落盘仍由 onChangeEnd 的 setter 负责)

3. **`lib/l10n/app_strings.dart`** — L381-383 附近新增:
   - `static String get settingsCardTextSizeTitle => '卡面文字大小';`
   - `static String get settingsCardTextSizeSubtitle => '放大复习卡片内的文字';`

4. **`lib/views/settings/widgets/settings_accessibility_section.dart`**:
   - `SettingsTextScaleTile`:divisions 5→**10**(步进 10%);`onChanged` 里除本地 `_dragValue` 外追加 `context.read<AccessibilityProvider>().previewTextScale(v.round())`(Slider 带 divisions 时 onChanged 仅在跨档时触发,每次拖动最多 ~10 次 MaterialApp 重建,可接受;每帧写 prefs 的旧顾虑只针对落盘,预览不落盘)
   - 新增 `SettingsCardTextScaleTile`(StatefulWidget,完整复制 textScale tile 的 `_dragValue`/图标/布局结构,读 `p.cardTextScale`,onChanged 调 `previewCardTextScale`,onChangeEnd 调 `setCardTextScale`,divisions: 10)

5. **`lib/views/settings/pages/accessibility_settings_page.dart`** — L35-36 的 textScale tile 之后插入 `const SettingsCardTextScaleTile()` + `settingsTileDivider(context)`

## B. 两条卡面 WebView 轨道接入 cardTextScale

6. **`lib/views/anki/anki_html_card_view.dart`**(Dart webview 轨道):
   - widget 新增 `final int textZoom;`(默认 100,构造参数带默认值,现有调用方零改动)
   - `_themedHtml()`(L294+):`if (widget.textZoom != 100) css.write('html{zoom:${widget.textZoom / 100};}')` — 只在 >100 时注入,默认 100 一个字节都不加,保真约定默认不变;高度上报链路(ResizeObserver)自动跟随 zoom 后的新高度,无需额外处理
   - `didUpdateWidget` 重载条件(L324-331)追加 `oldWidget.textZoom != widget.textZoom ||`
   - 更新 L278-281 注释:补充"opt-in 卡面缩放层(user cardTextScale > 100)例外"

7. **`lib/views/review/components/official_template_webview_body.dart`** — L31-37 构造 `AnkiHtmlCardView` 时传入 `textZoom: context.select<AccessibilityProvider, int>((p) => p.cardTextScale)`(StatelessWidget 的 build 里 select,provider 包已可用)

8. **`lib/views/anki_official/official_anki_reviewer_view.dart`**(原生轨道 Dart 侧):
   - widget 新增 `final int textZoom;`(默认 100)
   - `build()` 的 creationParams(L197-202)加 `'textZoom': widget.textZoom`
   - `didUpdateWidget`(L82-95)追加:若 `oldWidget.textZoom != widget.textZoom` → `_channel?.invokeMethod('setTextZoom', widget.textZoom)`(**不走 `_present()`**——缩放不应触发整卡重渲染/去重闸门)

9. **Kotlin `OfficialAnkiWebPolicy.kt`** — `apply(webView, diagnostics)` 增加 `textZoom: Int` 参数,函数体内 `settings.textZoom = textZoom`(WebSettings 集中配置点;textZoom 只缩文字不动布局,即时生效含 iframe,与"字体大小"语义一致;显式设置同时覆盖系统字体缩放,与 app.dart 根部"替换而非叠加" textScaler 的既有惯例一致)

10. **Kotlin `OfficialAnkiReviewerPlatformView.kt`**:
    - init 块解析 creationParams:`val textZoom = (creationParams?.get("textZoom") as? Int) ?: 100`,传给 `WebPolicy.apply`
    - `onMethodCall`(L167-203)新增分支 `"setTextZoom" -> { webView.settings.textZoom = (call.arguments as? Int)?.coerceIn(100, 200) ?: 100; result.success(null) }`(照抄 setTheme 分支样板)

11. **`lib/views/anki_official/official_anki_reviewer_stage.dart`** — L199-221 构造 `OfficialAnkiReviewerView` 处,build 顶部 `final cardTextScale = context.select<AccessibilityProvider, int>((p) => p.cardTextScale);`,传入 `textZoom: cardTextScale`

## C. 修复打字题输入框双重放大(`official_anki_reviewer_stage.dart` L131-146)
