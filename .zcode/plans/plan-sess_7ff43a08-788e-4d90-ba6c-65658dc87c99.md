# Anki 导入"题型选择"一级化 + 去 pro 化（步骤 1–4）

目标：把"选择题/填空题"等题型选择提升为导入预览的一级交互；删除旧版预览页的专家参数堆。识别与生成能力已存在（`NotetypeMappingType` 七类型 + 官方路径 `enabledKinds`），本次均为 UI/薄映射层改动，不动识别管线与投影策略。

## 步骤 1：用户面题型层（新建，纯 Dart）
新建 `lib/application/anki/import_wizard/question_type.dart`：
- `enum UserQuestionType { choice, fillBlank, listen, word, sentence, flip }`
- `userQuestionTypeOf(NotetypeMappingType)`：先 canonicalize（multiSelect→choice、typeAnswer/cloze→fillBlank），再映射
- `resolveMappingType(UserQuestionType, {required bool hasClozeMarkers})`：fillBlank 有 cloze 标记→`cloze`，否则→`fillBlank`；其余直接映射
- `hasClozeMarkers(AnkiNotetype, List<AnkiNote>)`：`notetype.isCloze` 或样本字段匹配 `{{c\d+::`

## 步骤 2：旧路径题型 chips
`lib/views/anki/import_wizard/anki_notetype_mapping_editor.dart`：
- `NotetypeMappingRow` 由 ListTile 改为卡片：标题行（notetype 名 + 卡数 + 状态图标），下方 `Wrap`+`ChoiceChip` 六项（选择题/填空题/听力题/单词卡/句子卡/翻卡片），当前类型预选；自动识别的结果加"自动"角标（判定：recognition.source==persisted && confidence>=1.0 为用户确认，否则视为自动）；新增 `onTypeSelected(UserQuestionType)` 回调，保留 `onEdit`（"调整字段"入口）
- `NotetypeMappingEditor` 对话框：题型 chips 提到对话框顶部（替换"更多调整"里的 7 项"卡片类型"下拉，下拉删除）；"更多调整"保留正/背面字段选择与识别依据；保留交换/恢复自动识别按钮
- `legacy_anki_import_preview.dart`：卡片识别区移到页面最顶部；chip 点击→`controller.saveLegacyMapping(mid, existingMapping.copyWith(type: resolveMappingType(...)))`（控制器与规则持久化已现成，业务层零改动）

## 步骤 3：官方路径"生成什么练习"
- 新建 `lib/application/anki_official/projection/official_exercise_presets.dart`：`enum OfficialExercisePreset { auto, choice, fillBlank, listen, flip }` + `presetKinds()`（auto=默认全集；choice=['multipleChoice','multiSelect','flip','canonicalLink']；fillBlank=['fillBlank','flip','canonicalLink']；listen=['listenPick','flip','canonicalLink']；flip=['flip','showWord','canonicalLink']）+ `presetOf(enabledKinds)` 反查 + `withPreset(suggestion, preset)`
- `official_anki_mapping_page.dart`：样卡预览之后、题目和答案之前加"生成什么练习？"区块（预设 chips）；选中→`copyWith(enabledKinds:)` 并 `onChanged`；`schema.kind=='cloze'` 时显示一行"挖空卡将生成填空题"提示
- 不改 mapper/service/policy——`enabledKinds` 已随 `toJson` 持久化、被 `CardPresentationPolicy.selectOfficialKind` 消费

## 步骤 4：旧版预览激进去 pro（用户已确认）
`legacy_anki_import_preview.dart`：
- 删除策略区：4 种策略 RadioGroup/StrategyOption 单选、CollisionStrip、"检测到 Section"行
- 删除智能分组、Section Beta 两个 SwitchListTile（默认值 true/false 不变，行为无变化；controller 的 setStrategy/setSmartGrouping/setSectionBeta 保留）
- 高级选项卡保留但收缩：副标题=一句白话摘要"重复的卡自动合并 · 自动按单元分组"；内部仅留组织结构摘要行（N 单元/M 课时 + 低置信提示）+ 学习进度开关
- 同步清理 `anki_import_wizard_widgets.dart` 中仅被删除 UI 使用的组件（CollisionStrip、StrategyOption、strategyLabel/Description/Consequence、mappingTypeLabel）；`app_strings.dart` 删除确认无引用的 ankiMappingType*、ankiStrategy*、ankiPreviewCollisionVisualHint、ankiSmartGrouping* 等字符串（删除前逐一 grep 确认）
