该模块是标准的 Flutter macOS Runner 工程，采用 Cocoa + Swift 作为原生外壳，通过 FlutterMacOS 框架承载 Flutter 引擎。
- 入口层：`Runner/AppDelegate.swift` 继承 `FlutterAppDelegate` 并标记 `@NSApplicationMain`，控制应用生命周期；`Runner/MainFlutterWindow.swift` 创建 `FlutterViewController` 并将其设为窗口内容控制器，完成 Flutter 视图嵌入。
- 插件注册：`Flutter/GeneratedPluginRegistrant.swift` 由 Flutter 构建系统自动生成，集中导入并注册所有 macOS 端插件（如 audioplayers_darwin、file_picker、flutter_local_notifications、shared_preferences_foundation、sqlite3_flutter_libs、url_launcher_macos 等），由 `MainFlutterWindow.awakeFromNib` 中的 `RegisterGeneratedPlugins` 调用。
- 构建配置：`Runner/Configs/` 下按 Debug/Release/DebugProfile 分离 xcconfig；`Flutter/ephemeral/` 存放 flutter pub get 生成的临时构建设置；`Podfile` 通过 `podhelper` 脚本调用 `flutter_install_all_macos_pods` 自动安装 Flutter 依赖的 CocoaPods 包，目标最低版本为 macOS 10.15。
- 资源与清单：`Runner/Assets.xcassets/AppIcon.appiconset/` 提供多尺寸应用图标，`Info.plist` 定义应用元数据，`*.entitlements` 控制沙盒权限。
- 测试：`RunnerTests/RunnerTests.swift` 提供原生单元测试模板。
依赖方向单向：Runner → FlutterMacOS → GeneratedPluginRegistrant → 各第三方 CocoaPods 包，无反向依赖。
