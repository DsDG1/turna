模块由三层构成：
- 顶层 `CMakeLists.txt` 定义项目 varnamala（C++17、/W4 /WX /EHsc、UNICODE），引入 `flutter/` 子目录（由 flutter 工具生成）和 `runner/` 子目录，并通过 `flutter/generated_plugins.cmake` 自动注册插件；安装阶段将可执行文件、ICU 数据、AOT 库及 `flutter_assets` 复制到同一目录以支持 VS 直接运行。
- `runner/` 是应用入口层：`main.cpp` 的 `wWinMain` 完成控制台附加、COM 初始化、构造 `DartProject` 并启动消息循环；`flutter_window.h/.cpp` 继承自 `Win32Window`，在 `OnCreate` 中创建 `FlutterViewController` 托管 Flutter 渲染；`win32_window.h/.cpp` 封装 Win32 窗口生命周期（Create/Show/Destroy）、WndProc 回调、DPI 感知与主题同步，提供 Point/Size 结构体作为跨 DPI 的尺寸抽象。
- `flutter/` 目录由 Flutter 工具自动生成（`generated_plugin_registrant.*`、`generated_plugins.cmake`、`CMakeLists.txt`），不包含业务逻辑，仅桥接 Dart 插件到 C++ 构建系统。
依赖方向单向向下：`main → FlutterWindow → Win32Window → Win32 API`，Flutter SDK 通过 `flutter/dart_project.h` 和 `flutter/flutter_view_controller.h` 暴露给 runner。
