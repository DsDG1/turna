- 窗口类采用继承扩展模式：`FlutterWindow` 继承 `Win32Window` 并重写 `OnCreate/OnDestroy/MessageHandler` 来注入 Flutter 视图逻辑，基类负责通用 Win32 窗口管理。
- 所有头文件使用标准 include guard（`#ifndef RUNNER_*_H_` / `#define ...` / `#endif`）形式，命名空间为 `RUNNER_<文件名>`。
- CMake 全局编译设置通过 `APPLY_STANDARD_SETTINGS(TARGET)` 函数统一注入 C++17、警告级别、异常开关等，新增选项应优先添加到该函数而非各 target。
- 资源与依赖通过 CMake `install()` 指令按组件（Runtime）安装到 `${BUILD_BUNDLE_DIR}`，保证可执行文件与其依赖在同一目录以便 Visual Studio 直接运行。
