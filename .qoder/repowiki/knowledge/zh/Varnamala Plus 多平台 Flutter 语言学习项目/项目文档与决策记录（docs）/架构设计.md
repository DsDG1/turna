本模块按用途划分为四个子目录：
- `analysis/`：从产品/用户视角对框架进行系统梳理（如 project-framework-analysis.md），描述分层结构、功能地图与学习闭环。
- `authoring/`：面向课程作者的契约与工具链说明，包含课程布局规范（course-layout.md）、GUI 编辑器指南、题型模板（templates/*.json）、导入流程等；模板以 JSON 定义 lesson 的 subLessons/stages/items 结构，作为 Flutter 渲染层与 CLI 验证的共同契约。
- `decisions/`：采用 ADR（Architecture Decision Record）编号格式（0021–0026），记录 Git 资源库架构、认证与凭据存储、分支冲突策略、团队协作增强、教材集成与本地编辑器增强等关键设计决策。
- 根目录：跨领域设计文档（anki-import-design.md 描述 Anki 牌组导入架构）、音频录制规范、以及由脚本生成的 content_inventory_current.md 内容清单。

依赖方向单向向下：Flutter 应用消费 authoring 中定义的 JSON 契约，CLI（tool/course_cli.py）与 GUI 编辑器遵循同一份 course-layout 规范，ADR 指导代码演进，三者通过版本号（index.json version + expressions.json version）触发 reseed。
