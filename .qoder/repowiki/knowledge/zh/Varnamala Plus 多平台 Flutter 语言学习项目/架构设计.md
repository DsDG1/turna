根目录作为 Flutter 单包工程（pubspec.yaml 定义），通过 Makefile 统一编排代码生成（build_runner）、Dart/Python/GUI 三层测试与发布流水线；flutter_app 为业务主模块，各 platform_* 子模块仅充当原生 Runner 壳，通过 MethodChannel/CMake/Xcode/Gradle 等各自平台的集成方式加载同一份 Dart 代码；assets 提供课程 JSON 与多媒体资源，被 flutter_app 在启动时通过 CourseLoader + DatabaseSeeder 注入 Drift SQLite 缓存；cli_tools 与 tests 分别面向内容生产与质量保障，二者共享 tool/ 下的 Python CLI（course_cli.py、build_release.py 等）；docs 集中 ADR 与 authoring 契约，约束所有子模块的数据格式与接口约定。
