- 所有课程 JSON 文件顶部统一包含 `version` 与 `language` 字段，便于版本管理与多语言路由。
- 课程层级严格遵循 index → sections → units → lessons → stages → items 的嵌套结构，每层元素均携带唯一 `id` 与可选的 `prerequisite*Ids` 前置依赖链。
- 题目项通过 `runtimeType` 字段声明渲染类型（如 `multipleChoice`、`showWord`、`translateSentence`、`fillBlank`、`reorderSentence`），而非使用不同对象结构。
- 词汇与表达条目统一使用 `id`（前缀 `w-` / `e-`）、`term`、`translation`、`pronunciation`、`tags` 的扁平结构，未提供的可选字段（如 `audioAsset`、`grammarPointId`）显式设为 `null`。
- 音频资源按用途分层命名：全局音效使用语义后缀（`error_1.mp3`、`level_up_3.mp3`），课程听力按 bgm/debut/fin 三类子目录组织。
