模块遵循 Clean Architecture 分层：
- `domain/` 定义纯 Dart 领域模型（如 `LocalUser`），不依赖任何框架。
- `data/` 通过 Drift (`CourseDatabase`) 将课程索引与内容持久化为 SQLite，配合 `DatabaseSeeder` 从 bundled JSON 资产初始化；web 平台不支持 NativeDatabase 会抛出 `UnsupportedError`。
- `application/` 放置所有 `ChangeNotifier` 状态的 Provider（主题、设置、课程、游戏、SRS、AI 辅助等），统一在 `providers.dart` 中注册为 `ChangeNotifierProvider`，并通过 `getIt<T>()` 解析共享实例。
- `views/` 提供 UI 入口 `VarnamalaApp`，使用 `MaterialApp.router` + `auto_route` 路由，并在根层应用无障碍 MediaQuery 覆盖。
- `di/injection.dart` 暴露 `GetIt` 单例与 `configureDependencies()`，由 `@InjectableInit` 生成代码完成声明式装配。
- `service/locator.dart` 负责异步原生服务注册（`StreamingSharedPreferences`、TTS、Drift DB 打开与播种、`TabRouter`、`ExportService` 等），`setupLocator()` 在 `main()` 中首帧前调用。
- `routing/routing.dart` 用 `@AutoRouterConfig` 声明页面路由，`CourseReadyGuard` 保证课程加载完成后才进入主页。
- `core/` 提供跨层工具（`logger` 基于 `package:logger`，按 release/debug 过滤日志级别）。
依赖方向严格单向：views → application → data/domain，通过 `di` 和 `service` 解耦。
