- 每个被测 Dart 文件在 `test/` 下有一一对应的 `*_test.dart`，并按原包路径镜像组织目录（如 `application/srs_provider_test.dart` 对应 `lib/application/srs_provider.dart`）。
- Flutter 测试统一以 `TestWidgetsFlutterBinding.ensureInitialized()` 开头，并在 `setUp` 中通过 `SharedPreferences.setMockInitialValues({})` 重置状态，避免跨测试污染。
- Golden 测试通过 `tester.binding.setSurfaceSize` 固定画布尺寸，并使用 `VarnamalaTheme.lightTheme` / `darkTheme` 分别断言 light/dark 两套截图。
- Python 测试使用 `unittest.TestCase` 子类，通过 `patch("module.subprocess.run", ...)` 和 `patch("module.shutil.*", ...)` 隔离外部命令与文件系统副作用。
- 需要数据库访问的测试通过 `seedInMemoryCourseDb()` 创建内存 CourseDatabase 并用 `CourseLoader.overrideDatabase` 注入，避免触碰真实文件系统。
- 测试命名采用 `group('...')` + `test('...')` 的 BDD 风格，对同一功能点按输入/边界/异常分组描述行为。
