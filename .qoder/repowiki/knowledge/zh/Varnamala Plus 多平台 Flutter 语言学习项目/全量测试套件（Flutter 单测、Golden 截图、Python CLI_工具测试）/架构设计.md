测试按被测模块的目录结构镜像组织：`test/anki/` 对应 Anki 适配器，`test/application/` 对应业务 Provider/Service，`test/core/` 对应核心算法（SM-2、streak 等），`test/courses/`、`test/data/`、`test/domain/`、`test/views/`、`test/routing/`、`test/service/` 一一对应 `lib/` 下的子包。`test/golden/` 存放 Flutter Golden 截图测试及 `goldens/`、`failures/` 基准图；`test/helpers/` 提供跨测试共享的辅助（如 `in_memory_course_db.dart` 通过 `CourseLoader.overrideDatabase` 注入内存 SQLite 数据库，并处理 Linux 上 `libsqlite3.so` vs `.so.0` 的 FFI 加载问题）。`test/tool/` 使用 Python unittest 直接 import `tool/` 下的脚本并通过 `unittest.mock.patch` 隔离 subprocess/shutil 调用。顶层 `BASELINE.md` 记录每次变更后的测试总数与关键回归说明，作为持续集成的基线快照。
