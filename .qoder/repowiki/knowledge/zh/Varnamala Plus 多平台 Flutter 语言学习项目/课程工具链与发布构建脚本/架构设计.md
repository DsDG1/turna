本模块由一组相互独立的 Python 脚本组成，围绕 `assets/courses/turkish` 下的 JSON 课程数据（index.json、sections/*.json、vocab.json、expressions.json、grammar_points.json）和 `assets/sounds/turkish` 下的音频资源工作：
- `course_cli.py` 是核心 CLI，提供 validate/export-csv/import-csv/lint/audio-manifest/diff 子命令，实现 Dart 端 `course_validator` 的 Python 等价逻辑，定义 Problem 数据类和 CourseValidationError 异常作为统一问题报告格式。
- `build_release.py` 是发布编排器，通过 `subprocess.run` 依次调用 flutter pub/get、build_runner、flutter build (apk/aab/web)、`course_cli.py validate|lint`、`export_content_inventory.py`，产出版本化 APK/AAB/Web 产物并归档到 `build/releases/<version>`。
- `generate_audio.py` 通过 MiniMax REST API（`MINIMAX_API_URL`、`MINIMAX_API_KEY`、可选 `MINIMAX_GROUP_ID` 环境变量）批量合成听力课 MP3，复用 `course_cli.is_listening_lesson` 判断听力课。
- `mix_listening_a1.py` 基于 pydub + ffmpeg 将 raw_a1 主音频与 debut/fin 片头片尾、bgm 背景音乐按 A/B/C 变体映射混合输出。
- `export_content_inventory.py` 扫描课程引用关系，生成 `docs/content_inventory_current.md` 及版本化副本。
- `split_course.py` 一次性将旧版 `kannada_lessons.json` 拆分为 per-section 布局。
依赖方向单向：构建脚本 → course_cli → 课程 JSON；音频脚本 → course_cli + MiniMax HTTP；无 GUI 依赖。所有写文件操作均采用 tmp + os.replace 原子写入模式保证崩溃安全。
