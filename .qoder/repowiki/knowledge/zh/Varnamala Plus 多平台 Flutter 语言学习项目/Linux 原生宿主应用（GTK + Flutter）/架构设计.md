该模块是 Flutter Linux 平台的原生宿主层，由 CMake 驱动构建，分为两层：
- `flutter/` 子目录由 Flutter 工具自动生成和维护（包含 `generated_plugin_registrant.*`、`generated_plugins.cmake`、`ephemeral/.plugin_symlinks` 以及 `CMakeLists.txt`），通过 `tool_backend.sh` 在构建时生成 `libflutter_linux_gtk.so` 及头文件，并以 INTERFACE library 形式暴露给上层。
- 顶层 `main.cc` / `my_application.{h,cc}` 实现 GTK 应用入口：`MyApplication` 继承自 `GtkApplication`，通过 `G_DEFINE_TYPE` 注册 GObject 类型，在 `activate` 回调中创建 `GtkWindow`、构造 `FlDartProject` 与 `FlView`，调用 `fl_register_plugins` 完成插件注册，并将 FlView 作为根 widget 嵌入窗口。
- 依赖方向单向向下：宿主仅依赖 `flutter_linux.h` 提供的 C API，不反向依赖 Flutter/Dart 源码；系统库通过 `pkg_check_modules(GTK)`、`GLIB`、`GIO` 发现。
- 安装产物遵循 Flutter 约定：二进制、`flutter_assets`、AOT 库 `libapp.so`、ICU 数据与插件动态库分别安装到 `bundle/{,lib,data}` 目录下，RPATH 设为 `$ORIGIN/lib` 以支持相对路径加载。
