## 失败结论

**Anki 底座 v2（ADR 0043 + 本文件夹六步）没有交付。按计划自己的完成标志，整条链失败，不是某一步「还差真机」。**

事实（以各步收据为准，不另编故事）：

1. **生产从未走 v2。** `v2ImportChain` 在 `productionAndroid` 保持 `false`。flag 翻 true 的前置（Step 4 C3 真机强杀矩阵全绿 + C4 大库 P95 定标 + 观察期）从未满足。
2. **Step 4 未关闭。** host 侧代码和假引擎测试落了；K1–K14 真机矩阵未跑，冷重建定标未跑。发布门禁用文档写着，没有证据。
3. **Step 5 / Step 6 未发生，也不再做。** 存量用户迁移（搬三样、升级实测、观察期）取消；不考虑「老用户」把 v1 数据迁进 v2。没有切过生产，就不存在「删 v1、只留 v2」的合格前置。双轨并存没有收口。
4. **目标一条没达到。** 课程树仍不是单一物化视图生产路径；catalog / course.db 旧表仍在；对账与副本仍在；代码量未降到计划的约 15k。Collection 作为唯一事实源只存在于设计文档。

本计划**没有下一步**。若以后另起架构，新开文档，不要续写 Step 5/6。

## 一、总目标（说人话版）

**让官方 Anki 的库文件（collection.anki2）成为唯一的事实源，Turna 只负责它真正擅长的事：教学流程和界面。**

做完之后应该达到的效果：

1. **导入一个牌组，课程树自动出现。** 中间不再经过 4 个数据库 38 张表，同一条数据只存一份。
2. **删除一个牌组，空间真的回来。** 不再有「删了还在」「越删越大」「要点手动优化才回收」。
3. **取消导入、删除牌组不再卡死。** 长操作能取消，卡住的操作有出路，界面不冻结。
4. **课表结构和字段映射的决策存在 Anki 库自己身上**（它自带的配置区），备份、导出、将来做云同步都自动跟着走；Turna 这边的派生数据丢了随时能重建。
5. **代码量从约 33k 行降到 15k 行左右。** 不是为了删而删——数据不重复了，为对账而生的那一堆代码（对账器、普查、修复中心、写栅栏）就没有存在的理由了。

## 二、为什么值得推倒（现状一句话诊断）

现在「导入→课程树」这条链，**同一个事实存了 2~4 份**：课程树三份、版本指纹四份、牌组来源登记表两份、卡片内容三份。为了不让这些副本打架，系统长出了一整套「免疫系统」——对账、普查、修复中心、写栅栏——这部分占了代码量大半，也是怪 bug 的温床。已经核实存在的问题：

- 删除牌组后空间不回收：回收任务在 App 启动时被一个空值判断整个跳过，只有用户手动点「优化数据库」才跑。
- 存储页的「删除残留文件」是幽灵操作：弹窗说清理成功，文件一个字节没少。
- 大库的删除/优化在界面线程上同步执行，会冻屏，而且不能取消。
- **一个更大的隐患：生产环境的导入链可能根本跑不通。** 临时库的引擎建好后，没有谁调用「打开库」就直接发起导入，而引擎规定必须先打开。测试全是绿的，因为测试用的都是假引擎，而假引擎那条分支恰好调了打开——测试绿说明不了真机行。这一点还没在真机上验证过，是 Step 1 要第一个回答的问题。

好消息：**真正值钱的东西都不用重写。** Rust 桥、后台工作线程、staging 导入的思路、复习会话层、字段识别器、渲染层——这些是资产，原样保留。

## 三、什么不动，什么重做

### 不动（约占四成代码量）

| 保留的东西 | 为什么留 |
|---|---|
| Rust 桥 + 钉住的 Anki 内核（40 个操作接口） | 地基本身没问题，接口编号只加不改的纪律也值得保留 |
| 后台 isolate 会话架构 | 引擎调用全在后台线程、取消通道独立——设计是对的 |
| staging 导入思路（先落临时库、确认后才碰正式库、取消=删目录） | 这是治理「不可逆操作」的正确姿势，v2 原样继承 |
| 复习会话层（队列、答题回执、撤销） | 和这次重构无关，测试覆盖最厚 |
| 字段识别器（判断哪个字段是正面/背面/音频） | 只产决策不碰存储，直接喂给新架构 |
| 渲染层（卡面渲染、填空、打分对比） | 已经在正确地用 Anki 原生能力 |

### 重做（大部分）

| 现状 | 重做之后 |
|---|---|
| 课程树三份副本 | 一份物化视图，随时可从 Anki 库重建 |
| 目录库 18 张表 | 约 4 张（来源、导入尝试、维护任务、租约） |
| course.db 里 20 张 anki 表 | 约 5 张 |
| 字段映射决策存在目录库 | 存进 Anki 库自带配置区，随备份导出走 |
| 删除 = 11 张表级联 + 双登记表同步写 | 一个事务删干净 + 引擎垃圾回收 |
| 维护任务接线断裂 | 挂到引擎会话建立之后，自动跑 |
