## 品牌规则要点（浅色已确认，深色 / 200% / 高对比样稿已核对）

| 主题 | 决定 |
|---|---|
| 色彩 | 品牌 hex 不变；整屏约 70% 中性 / 20% 湿地冷色 / 10% 暖点缀；玻璃派生色统一由主题计算，页面不写裸色 |
| 材质四类 | 纸面（目录 / 正文 / 弹层正文，排版 + 中性细边）、雾面彩玻璃（四色：雾青灰=弱强调、水鸭青=练习与复习主卡、暖沙=成就衬底、陶土=完成重点；低彩度 + 顶部宽亮部 + 边缘积色 + 冷柔影）、扁平控件（按钮 / 选项 / 词条）、磨砂浮层（底部胶囊与 SnackBar） |
| 玻璃用量 | 一页通常只有一个玻璃对象；长列表不铺玻璃；高对比全撤（GlassMode.off，状态靠轮廓与形状） |
| 几何 | 圆 / 半圆 = 积累与今日，拱形 = 章节与旅程，弧线 = 复习涟漪，斜切 = 边界；题面不再放装饰图形（评审决定）。**页级形态必须贴边**：`arch` / `diagonalCut` / `ring` 画到方框之外，靠被屏幕或卡片边缘切掉才成立，放进方框中央就退化成贴纸。只放在「露底色」或「半透明玻璃」的位置，不透明纸面会把它们整个盖住（详见 ADR 0068 补记） |
| 排版 | 页面标题 28–36 / 700，区块标题 18–20，正文 16，辅助 13，题面 20–36 按题型；200% 缩放下分区与动作带结构不变，只换行加高 |
| 栅格 | 主边距 24 / 紧凑 16，节奏 8 / 12 / 16 / 24 / 32 / 48；学习主列 ≤720，统计与表单 ≤840 |
| 外壳（R01） | 轻顶栏（课程名 + 切换 + 连胜），状态数字离开顶栏进入所属页面；底部水平文字导航 + 受光短条标记当前 Tab |

## 全局版面模式（七型 + 全局弹层）

| 模式 | 结构 | 承载页面 |
|---|---|---|
| 学习旅程 | 紧凑章节头（可点击切换）→ 三层目录（吸顶单元条 / 课时行 / 子课行）→ 底部常驻「继续」条 | 课程主页（R02） |
| 沉浸作答 | 顶：退出 + 分段进度 + 计数；中：大题面或回忆画布；下：独立动作带 / 评分带 | 课时（R04–R05）、全部会话（R07–R08） |
| 今日任务台 | 一个数字 + 一个主行动 → 有顺序的队列行 → 文字工具索引 | 练习（R07）、记忆卡中枢（R13） |
| 学习报告 | 一个核心指标开篇 → 主图独立段落 → 辅助指标按解释顺序 | 洞察 / 进度 / 错题仪表盘 / 牌组统计（R09–R10、R13） |
| 阅读目录 | 排版目录行（词头 / 标题 + 释义 + 元信息），发丝线分隔 | 词典（R11）、收藏讲解、更新日志、隐私长文 |
| 偏好目录 | 落地页：快捷值条 + 图标目录；深页：分区标题 + 连续表单行（值右对齐） | 设置（R16）、AI 连接（R14）、备份（R17） |
| 步骤流程 | 顶部阶段说明 + 中央单焦点 + 底部固定阶段操作 | 导入向导（R12）、课程包导入（R03） |
| 全局弹层 | 拖手 + 标题 + 一句说明 + 可滚动正文 + 操作区（次左主右，危险操作红色动词）；dialog 同构 | 全部 sheet / dialog（R18） |

## 逐族线框决定（R01–R18）

- **R01–R03**：启动保持闸门语义；外壳见上；课程主页三层目录可滚动、未展开单元只占一行摘要，继续条常驻底部（用户已确认紧凑稿）；课程管理包含语言课程与记忆卡牌组（ADR 0067），保留「从记忆卡导入课程」卡。
- **R04–R06**：课时沉浸壳；题面无装饰图形（评审决定）；选项为编号行；主 CTA 位置跨题型稳定（底栏）；完成体验收敛为「几何完成标记 + 结果一行 + 收获纵向 + 单一下一步」，不再用 85% 屏高弹层堆叠（完成页细节随 P3 课时域定稿）。读卡类（`autoAdvance`，无底栏）在画布内**垂直居中**：这类卡没有解析可长，贴顶会让画布下半截空着；作答卡保持贴顶，提交后长出的解析不会把整卡顶上去。
- **R07–R10**：会话外壳统一（统一复习 / 正式记忆卡 / 语法三相位 / 课时壳同一骨架，仅上下文行不同）；错题列表 = 学习笔记式（作答对照主体 + 来源时间旁注 + 稳定重练动作）；洞察 / 进度 / 仪表盘 / 牌组统计共用报告构图；来源行真实下钻（修正假 chevron）。
- **R11–R13**：词典 = 词条阅读目录；导入向导流程原样、只重组视觉三段式，完成动作支持立即学习切课或查看牌组（ADR 0067）；卡牌浏览器与词典共享搜索 / 防抖 / 懒行基元；牌组统计并入报告构图；修复中心 = 健康摘要 + 问题列表 + 原位恢复。
- **R14**：AI 大厅 = 任务目录（引擎状态一行化）；练习库三组目录化、五态行内表达；聊天 = 连续会话 + 独立输入区；诊断 = 结论 → 依据 → 建议 → 行动；API 配置入偏好目录表单模式；深链直达 AI 页的平台防护维持引擎层兜底。
- **R15**：个人 = 学习档案（身份 + 一句概览 → 今日一行 → 学习积累四数 → 记录与成就章节行）；成就 = 完成度开篇 + 筛选 + 徽章网格，详情走全局弹层；装饰商店 = 预览与选择工作区。
- **R16**：落地页已确认（快捷值条 + 图标目录）；深页共用「分区 + 连续表单行」模式；Anki 每日上限随牌组课程管理（ADR 0067）；平台条件入口的「隐藏 vs 禁用并解释」按 B8 规则统一后落 P4。
- **R17**：备份 = 连接 → 最近结果 → 当前操作工作流；系统健康 = 等级开篇 + 需注意 + 操作目录；存储 = 总量 + 构成条 + 清理与明细分组，明细下钻页路由化。
- **R18**：关于 = 品牌开篇 + 链接目录，隐私 / 更新日志共用阅读目录模式与公共 SectionHeader / ContentCard（修三胞胎）；全局弹层模式如上。

## P2 输入（组件系统要新建 / 收敛的）

1. 会话骨架组件（进度头 + 回忆画布 + 阶段动作带 / 评分带），替换三套复制实现。
2. 报告构图套件（核心指标头 / 构成条 / 柱状 / 折线 / 热图 / 定义列表）。
3. 目录行族（课时行、任务行、词条行、表单行、链接行）与全局弹层 / 确认弹层。
4. 搜索基元（防抖 + 懒行预览）供词典与卡牌浏览器共用。
5. 外壳：轻顶栏 + 文字导航 + 受光标记；状态胶囊退役。
