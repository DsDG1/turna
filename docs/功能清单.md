## 1. 应用架构

### 架构模式
- **Clean Architecture**：三层分层（Domain / Application / Data / Views）
- **状态管理**：Provider + ChangeNotifier
- **依赖注入**：GetIt + Injectable 注解
- **路由**：Auto Route 代码生成 + Cupertino 风格导航
- **数据模型**：Freezed 不可变数据类 + JSON 序列化
- **数据持久化**：SQLite（Drift ORM）

### 层级结构
```
lib/
├── application/    # 状态管理（Provider 层）
├── core/           # 工具函数、枚举、SM-2/FSRS 算法
├── courses/        # 课程数据加载与验证
├── data/           # 仓库实现（Repository）
├── di/             # 依赖注入配置
├── domain/         # 领域模型 + 仓库接口
├── routing/        # 路由配置 + 守卫（Guard）
├── service/        # 应用服务（TTS、偏好设置、提醒）
└── views/          # UI 层（按功能模块组织）
```

### 数据流
```
UI (Widget) → Provider (ChangeNotifier) → Repository (Interface) → Data Source (SQLite/SharedPreferences)
```

## 2. 课程系统

### 课程结构（四层树形）
```
Section（章节）→ Unit（单元）→ Lesson（课程）→ Stage（阶段）→ Interaction（交互题）
```

- **Section（章节）**：CEFR 分级（A1→B2），支持先修章节依赖
- **Unit（单元）**：主题分组，含先修单元依赖
- **Lesson（课程）**：五种课程类型，支持先修课程依赖
- **Stage（阶段）**：课程内部的阶段划分（如"词汇"→"练习"→"听力"→"阅读"）
- **Interaction（交互题）**：13+ 种不同的练习题型

### 课程类型（LessonType）
| 类型 | 说明 | 图标 |
|------|------|------|
| `normal` | 普通课程 | 📖 |
| `listening` | 听力课程 | 🎧 |
| `reading` | 阅读课程 | 📄 |
| `review` | 复习课程 | 🔄 |
| `challenge` | 挑战课程 | 🏆 |

### 课程模板（LessonTemplate）
- `intro` — 介绍模板
- `practice` — 练习模板
- `review` — 复习模板
- `mastery` — 掌握测试（80% 正确率通过）
- `reading` — 阅读模板
- `legacy` — 传统模板

### 课程数据
- 格式：JSON（`assets/courses/turkish/`）
- 加载：`CourseLoader` → 导入 SQLite（`DatabaseSeeder`）
- 验证：`CourseValidator` — 验证章节结构完整性
- 版本：`contentVersion` 检测，版本变更时提示用户重置进度

### 课程树（Course Tree）
- 主页面"学习"标签页
- 章节切换器（Section Switcher）
- 单元手风琴折叠（Accordion）
- 课程状态徽章：已完成 / 待复习 / 弱词
- 虚拟化列表（SliverList）— 大单元性能优化
- 梯度背景（Course Tree Gradient）

## 3. 交互题型

共 **13 种** 交互题型，涵盖读写听说各方面：

### 词汇/展示类
| 题型 | 说明 |
|------|------|
| `ShowWord` | 展示词汇项，含上下文句子和表达链接 |

### 选择题类
| 题型 | 说明 |
|------|------|
| `MultipleChoice` | 单选（N 选 1），支持音频/图片附件 |
| `MultiSelect` | 多选（N 选 M），支持最小/最大选择数限制 |

### 填空/翻译类
| 题型 | 说明 |
|------|------|
| `FillBlank` | 完形填空，支持音频/图片附件和提示 |
| `TranslateSentence` | 翻译句子，支持多提示 |

### 听力类
| 题型 | 说明 |
|------|------|
| `ListenAndPick` | 听音频选答案 |
| `TypeTheWord` | 听写（听音频打字） |
| `ListenOnly` | 仅听（无评分，用于听力总结阶段） |

### 语法/排序类
| 题型 | 说明 |
|------|------|
| `ReorderSentence` | 打乱词序重组句子 |

### 阅读理解类
| 题型 | 说明 |
|------|------|
| `ReadingMcq` | 阅读理解选择题 |
| `ReadingTrueFalse` | 阅读理解判断对错 |
| `ReadingShortAnswer` | 阅读理解简答题 |

### Anki 类
| 题型 | 说明 |
|------|------|
| `AnkiCard` | 翻转卡片（正面→反面），支持音频/图片附件 |

### 辅助功能
- 每道题可关联 `grammarPointId` → 错误时自动加入语法复习队列
- `interactionAiHintEligible` — 判断该题是否可调用 AI 提示
- 错误时记录 `MistakeEntry`（含完整交互快照）

## 4. 学习活动

### 4.1 课程学习（主路径）
- **入口**：学习标签页 → 课程树 → 展开单元 → 点击课程
- **流程**：Stage 0 → Stage 1 → ... → 完成对话框
- **完成对话框**：展示正确/错误数、用时、XP 获得、宝石获得、完美课程奖励
- **掌握测试**：80% 正确率通过，失败可重试
- **进度条**：AppBar 底部线性进度条
- **破解模式**：自动提交正确答案 + 自动推进（Fun Lab 功能）

### 4.2 课程完成副作用
由 `LessonCompletionCoordinator` 统一协调：
- XP 奖励（基础 + 完美奖励）
- 宝石奖励（基础 + 完美奖励）
- 课程完成记录
- 成就里程碑检查
- 学习统计记录

### 4.3 Play Hub（游戏中心）
主页面第二个标签页，包含三大区域：

#### 快速游戏
- **Match Madness（单词配对）**：90 秒限时配对游戏，8 对/轮，无限轮次，持续替换新词

#### 今日重点（横向滑动卡片）
- **错误复习**（Mistake Review）：最近错误的 10 道题重做
- **SRS 复习**（SRS Review）：到期的词汇卡复习
- **每日挑战**（Daily Challenge）：15 道随机抽题

#### 复习中心（2×2 网格）
- **弱词复习**（Weak Words）：30 天内 ≥2 次错误的词
- **语法复习**（Grammar Review）：到期的语法点复习
- **Anki 复习**（Anki Review）：导入的 Anki 卡片复习
- **SRS 复习**（SRS Review）：词汇复习

#### 工具
- **复习进度**（Review Progress）：SRS 统计面板
- **词典**（Dictionary）：搜索词汇、表达、语法点

### 4.4 Match Madness（单词配对游戏）
- 90 秒倒计时
- 每轮 8 对（英语 ↔ 目标语言）
- 匹配后自动替换新词对
- 计分：每对 +2 XP
- 轮次过渡动画
- 游戏结束庆祝动画（闪亮/奖杯/闪电三种类型）
- 无限轮次

### 4.5 每日挑战（Daily Challenge）
- 从所有已加载课程中随机抽取 15 道可评分题
- 排除 `ShowWord` 和 `ListenOnly` 类型
- 可选排除 Anki 导入内容
- 复用 `LessonViewModel` 完整流程

### 4.6 错误复习（Mistake Review）
- 从错误日志中取最近 10 条
- 恢复每条错误的完整交互快照
- 逐题重做，正确后从错误日志中清除
- 避免反馈循环（`recordMistakes: false`）

### 4.7 弱词复习（Weak Words）
- 聚合条件：30 天内，同一 wordId 错误 ≥2 次
- 最多 10 题
- 题型：MCQ（词义选择）+ 听写（无对应翻译时）
- Anki 弱词回退到翻转卡片

### 4.8 语法复习（Grammar Review）
- 独立的 SRS 队列（`grammar` 队列）
- 复习语法点解释和示例
- 与词汇 SRS 使用相同的 FSRS 算法

## 5. SRS 间隔重复系统

### 核心算法
- **FSRS（Free Spaced Repetition Scheduler）** — 默认算法（ADR 0028）
- **SM-2** — 测试用备选
- **二叉评分**：Pass/Fail（记住/没记住），无 1-4 级评分 UI

### 可配置参数
- **目标保留率**（Desired Retention）：0.80–0.95，默认 0.9
- **自定义 FSRS 权重**：可通过优化导入
- **优化信息**：优化时间、优化时使用的复习次数

### 两套队列
| 队列 | 提供者 | 管理对象 |
|------|--------|----------|
| `srs` | `SrsProvider` | 词汇（word）+ 表达（expression） |
| `grammar` | `GrammarReviewProvider` | 语法点（grammar point） |

### SRS 状态（SrsWord）
- 间隔天数（intervalDays）
- 稳定性（stability）— FSRS 特有
- 难度（difficulty）— FSRS 特有
- 到期时间（dueAt）
- 上次复习时间（lastReviewedAt）
- 重复次数（reps）
- 遗忘次数（lapses）
- 水蛭标记（isLeech）— 慢性遗忘卡降级
- 卡类型（SrsItemType：word / expression）
- 同天失败阶梯（same-day fail ladder）

### 功能特性
- 课程学习时自动注册 SRS 词条
- 课程完成时记录课程链接（LessonLinkStore）
- 到期缓存（due cache）— 避免频繁重算
- 复习历史记录（ReviewHistoryDao）→ 记忆曲线分析
- 预置迁移：从 SharedPreferences 迁移到 SQLite（schema v7）

## 7. AI 功能

### 7.1 AI API 配置
- Base URL（默认：https://api.deepseek.com）
- API Key
- 模型名称（默认：deepseek-v4-pro）
- **配置仅在内存中**，不持久化

### 7.2 AI 课程生成（AiCourseProvider）
- 从课程规格（AiCourseSpec）生成 JSON 课程
- 支持内容锚定模式（grounded mode）— 基于已有资源生成
- 自动验证 + 自我修复（C3 Self-Heal）
- 预览并编辑 JSON
- 保存到 SQLite 数据库
- 刷新课程缓存

### 7.3 愿望模式（AiWishProvider）
- 对话式课程设计（"我想学餐厅用语"）
- 多轮对话对齐需求
- 生成课程 JSON
- 生成课程说明（中文）

### 7.4 课内 AI 提示（AiHintProvider）
- 点击 AI 按钮 → 弹出解释面板
- 中文教学助手，不直接给答案
- 支持追问（对话式）
- 按题型类型智能提示
- 协处理器（generation token）避免竞态

### 7.5 AI 课程助手（AiLessonHelperProvider）
- 整课视角的 AI 辅助
- 课程内容概览与学习建议

### 7.6 小艺集成（HarmonyOS）
- HarmonyOS 原生小艺助手
- "用小艺解答"开关
- 调用小艺直接解答问题

### 7.7 教材导入（Textbook Import）
- 导入教材 → AI 解析 → 生成课程
- 知识提取 + 冲突检测 + 合并策略
- Markdown 切分

## 8. Anki 集成

### 8.1 Anki 导入（AnkiImporter）
- 支持 `.apkg` / `.colpkg` 格式
- 基于 ZIP + SQLite3 FFI 解析
- 解析：牌组、笔记类型、笔记、卡片、复习日志、媒体映射
- 分页读取（每页 500 条）
- 进度回调 + 取消支持
- SHA-256 源文件哈希（去重检测）
- **不支持 HarmonyOS**（SQLite3 FFI 无 OHOS 构建）

### 8.2 Anki 导入流程
- 选择文件 → 解析 → 预览（牌组选择、笔记类型映射）
- 适配为 Varnamala 课程结构
- 导入 SRS 状态（AnkiSrsMigrator + AnkiCardAdapter）
- 媒体文件提取与链接

### 8.3 Anki 复习
- 每日新卡上限（new cards/day）
- 每日复习上限（reviews/day）
- 按到期时间排序（最逾期优先）
- 一次最多 20 张
- 支持按牌组筛选

### 8.4 Anki 牌组管理
- 牌组列表查看
- 每日限制管理
- 牌组卸载（删除相关 SRS 条目）
