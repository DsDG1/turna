# 内测说明（Android）

> 发给测试员的一页说明。维护者的分发配置见 [`firebase-app-distribution.md`](./firebase-app-distribution.md)。

## 1. 安装（约 3 分钟）

1. 用收到邀请的**同一个邮箱**登录，安装 **Firebase App Tester**（Google Play）。
2. 打开邀请邮件里的安装链接，在 App Tester 里点安装。系统提示「允许安装未知应用」时，允许这一次。
3. 需要 **Android 7.0 及以上、arm64 机型**（近几年手机基本都是）。32 位机、x86 模拟器装不上。
4. 之前装过别的签名的 Turna 的话，**先卸载再装**，否则会报签名不一致。

## 2. 主流程（约 15 分钟，请完整走一遍）

1. 首次启动，过完引导。
2. 导入一个 Anki 牌组：课程页的「从 Anki」，或练习页「Anki 复习 → 导入牌组」。
   - 手头没有 `.apkg`：Anki 桌面端 File → Export，选 `.apkg` 导出即可。
3. 打开刚导入的课程，**学完一课**（第一遍只解锁卡片）。
4. 练习页 →「Anki 复习」→ 开始复习 → 看正面 →「显示答案」→ 点「不记得」或「记得」。
5. 从后台彻底划掉应用再打开，确认课时进度和刚才的复习记录**都还在**。

## 3. 顺手试试（可选，没条件就跳过）

- 设置 → 数据与备份 → 远程备份（有自己的 WebDAV 再试，没有跳过）。
- 设置 → 系统健康与诊断 → 有异常就点「导出」。
- 深色模式、字号调到最大后再翻一遍复习卡片。

## 4. 出问题怎么报

每条问题给四样，缺一样都很难定位：

1. 机型 + Android 版本；
2. 应用版本：设置 → 关于 Turna；
3. 操作步骤：点哪里 → 看到什么 → 你以为会发生什么；
4. 截图或录屏。

崩溃、白屏、导入卡住时，再附一份「设置 → 系统健康与诊断 → 导出」的**脱敏诊断报告**。发回给邀请你测试的人即可。

## 5. 已知限制（这些不用报）

- 本轮只发 **arm64 的 Android 包**；iOS / 鸿蒙另行发放，流程从第 2 步起相同。
- 大牌组（上万张卡）导入、首次进课程要等几秒到十几秒，属正常。
- 复习评分是**两档**（不记得 / 记得），不是四档，这是设计如此。
- 数据只存在本机，没有云端账号；**卸载会清空**。测试期间别轻易卸载，换设备先用远程备份。
