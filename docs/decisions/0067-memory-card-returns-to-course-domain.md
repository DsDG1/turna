# ADR 0067 — 记忆卡回归课程域

> 状态：已接受｜日期：2026-11-04
>
> 取代：[ADR 0066](./0066-anki-deck-domain-independence.md)（记忆卡域独立于语言课程域）
>
> 前置：ADR 0037（Anki 课程与复习大一统，本文恢复的正是其界面口径）、ADR 0042 / 0043（staging-first 官方导入与单一事实源）、ADR 0050（鸿蒙 Official Anki 全档）、ADR 0057（记忆卡适配方案）

## 背景

ADR 0066 把记忆卡做成独立域：新建「记忆卡中枢」作为域首页并挂在练习台，课程管理过滤掉牌组条目，`CourseProvider.setScope` 拒绝 anki scope，导入完成不再切换课程。产品口径随后修订：**导入的记忆卡牌组就是课程**——出现在课程管理列表、可切换为当前课程、在学习 Tab 长出课程树、从课程管理导入；练习工具里不再有记忆卡入口。即恢复 ADR 0037 的界面形态。

用户口径的三个要点：①练习工具里的记忆卡恢复成导入课程；②语言课程不掺记忆卡（语言课程的课程树、课时、语言练习队列仍只含语言内容——这一点 ADR 0066 与本文一致，继续有效）；③Official Anki 引擎、导入管线（staging-first 五步向导、v2 发布链、适配方案）、数据层全部不动。

## 决策

### 1. 记忆卡牌组以课程形态出现

- 课程管理列出内置语言课程 + 每副导入的记忆卡牌组（一条目一来源）：点按切换当前课程、拖拽排序、精确来源确认后卸载；官方来源的行菜单保留适配方案恢复（ADR 0057 §6）。
- 「添加课程」区恢复「从记忆卡导入课程」卡（五步向导不变）与未完成导入横幅；AppBar 保留修复中心入口。
- 记忆卡课程激活时，学习 Tab 的课程树显示该牌组的 section / unit / lesson 投影（`_sectionInScope` 的 anki 分支自 ADR 0037 起未变）。

### 2. 导入完成恢复切课

- 「立即学习」= 切换到新导入的牌组课程并返回学习 Tab（全 App 唯一切课的完成动作，ADR 0043 口径）。
- 「查看牌组」= 打开课程管理并高亮新条目，不切课。

### 3. 练习台与个人页按当前课程裁剪

- `CourseProvider.setScope` 重新接受 anki scope；持久化的 anki scope 原样恢复（卸载兜底仍回退内置课程）。
- 练习台：记忆卡课程激活时语言三队列（错题 / 单词 / 语法）让位给一行「记忆卡复习」（点按直开正式复习，长按浮窗看构成；同步失败显示「—」+ 页内重试条）；智能练习行常驻。语言课程激活时无任何记忆卡入口，工具索引亦无记忆卡链接。
- 个人页快捷入口：记忆卡课程激活时换成单枚记忆卡 chip。

### 4. 记忆卡中枢撤销

- `MemoryCardHubPage` 及其路由删除。牌组管理职责回归：课程管理（列表 / 切换 / 卸载 / 适配恢复 / 修复中心 / 未完成导入横幅）与 `AnkiReviewPage`（牌组行、浏览卡牌、牌组统计、卸载）。

## 保留的 ADR 0066 产物

- `turna.course.scope` 配置区越界写的删除保留（课程 scope 只持久化于 prefs；该配置键无读方）。
- 语言课程域不掺记忆卡内容的原则保留（对语言 scope 过滤 anki section 的逻辑未动）。

## 范围外

- 数据与引擎层零改动：课程目录、`anki_sources` / `anki_course_tree_view`、`ReviewItem`、正式会话宿主、`FormalReviewLauncher` 契约不变。
- 鸿蒙 Official Anki 口径不变（ADR 0050）；内部契约命名（`anki-` 前缀、协议键、表名）不动（AGENTS §7.2）。

## 影响面

- `CourseProvider`：`setScope` 接受 anki scope、prefs 恢复不钳制、`ankiDeckEntries` 窄缝删除。
- 课程管理页、练习任务台、个人页快捷入口、导入向导完成步按上述口径重接；记忆卡中枢页与其专属文案删除。
- 门禁：`formal_review_launcher_test` 的生产入口清单仍然成立（练习台 / 个人页 / 记忆卡复习页都走 `FormalReviewLauncher`）。
