# ADR 0063 — 设置域深层页的弱化玻璃档

> 状态：已接受 ｜日期：2026-11-01
>
> 前置：ADR 0062（彩色玻璃材质：白纸上的淡彩玻璃）
>
> 真源：`lib/core/theme.dart`（`GlassLevel` / `GlassSpec`）、`lib/views/widgets/glass_surface.dart`
>
> 关联：ADR 0062 §2 的层级表由本 ADR 追加第五层

## 背景

ADR 0062 把全 app 的卡面统一成「白纸上的彩色玻璃」，并按角色分了四层：`L1` 内容卡、`L1Subtle` 表单卡（长列表）、`L2` 浮起面、`L3` 徽章。

设置域是 `L1Subtle` 的主消费者。落地页之下，**二级分类页与更深的下钻页**（存储与性能、系统健康、远端备份、头像环、AI 连接、关于 Turna、隐私详情、更新日志、透明度日志、官方 Anki 修复中心）几乎每屏都是玻璃卡：长列表、密集表单、成排的开关与分段控件。

`L1Subtle` 的白高光（sheen 0.34）会在卡片顶部压出一条横贯的亮带，两层同色相投影（近层 0.15 / 远层 0.11，远层 blur 28）又把整张卡托离纸面。两者叠起来，读出来是**塑料片**而不是「纸上的玻璃」：在这种一屏七八张卡的密度下，玻璃感压过了内容本身，表单控件退到背景里。

同一批页面里还留着**一代**的白描边 `glassBorder`（白 50% / 深 15%）。按 ADR 0062 的定位，`glassBorder` 服务的是**浮起 chrome**（AppBar / chip / SnackBar / 胶囊导航），而这些页面里的白描边用在**内容卡与控件**上 —— 一代白高光边压在淡彩卡面上会读作「描边缺失」（ADR 0062 §1 的原话），在一代模型里是缺陷，在二代模型里是**用错档位**。

## 决策

### 1. 新增第五档 `l1Quiet`，而不是下调 `l1Subtle`

`L1Subtle` 是公共色阶：词典、复习进度、错题列表、学习洞察、课程管理、官方 Anki 修复中心等长列表页都在用。调它的参数等于让本次范围之外的页面一起变 —— 这不是本次要解决的问题。

`L1Quiet` 是**同色阶、更弱高光与投影**的新档，只在设置树深层使用。层级表变成五层：

| 层 | 用途 | 淡彩 | 白高光 | 描边 | 投影 |
|---|---|---|---|---|---|
| L1 | 内容卡 | accent 9→16% | 34%→0 @40% | accent 26% | 16% y6 r10 + 13% y16 r34 |
| L1Subtle | 表单卡 / 长列表 | accent 7→13% | 34%→0 @40% | accent 24% | 15% y5 r9 + 11% y14 r28 |
| **L1Quiet** | **设置域深层页** | **accent 7→13%** | **8%→0 @40%** | **accent 20%** | **6% y2 r6 + 3.5% y9 r20** |
| L2 | 浮起面 | accent 11→19% | 40%→0 @42% | accent 40% | 18% y5 r10 + 12% y12 r22 |
| L3 | 徽章 / 标签 | accent 13% 平涂 | — | — | 无 |

### 2. 淡彩浓度不动，只削高光与投影

`L1Quiet` 的淡彩与 `L1Subtle` **完全同值**（浅色 7→13%，深色 8→14%）。

这是硬约束，不是保守。`l1Subtle` 的参数表注释已经记录过一次实测：中性灰 accent 彩度天然低，**浓度降到 5→9% 在白底上等于消失**。设置域的卡面 accent 就是中性灰 `glassNeutral` —— 淡彩一降，卡片在白纸上就没有边界了，「弱化」会变成「消失」。

因此弱化只能落在另外两个维度上：**顶部白高光**（0.34→0.08）与**双层浮起投影**（近层 0.15→0.06、远层 0.11→0.035）。玻璃感的读出来自这两者，不是来自色浓度。削掉它们，卡面就**退成纸面**，让位给表单控件；边界仍在（描边 20% + 极弱近影）。

深色分支同理：`darkSheen` 0.05→0.02（顶部白高光），两层黑投影按档位取 0.07 / 0.12。

### 3. 一级落地页保留既有强度

设置落地页（`SettingsPage`）是设置域的**视觉锚点** —— 顶部个人摘要卡 + 快捷设置格 + 分类入口组，靠的是品牌渐变与玻璃的对比。分类页与更深的下钻页才降到 `L1Quiet`。

落地页的两处 `SettingsCard` 因此**显式**传 `GlassLevel.l1Subtle`，而 `SettingsCard` 的默认值是 `l1Quiet`（设置树深层占 27 处调用，落地页只占 2 处）。这个切换是单点可逆的：删掉两处显式参数，落地页即随之弱化。

### 4. 一代白描边在内容卡上收口为二代同色相描边

设置树内 5 处内容卡 / 控件改用二代 `glassStroke`（同色相描边）：

- AI 连接页的状态面板 —— 直接用 `glassDecoration(level: l1Quiet)`，吃到渐变 + 同色相描边 + 弱投影
- AI 连接页的供应商选择控件（未选中态）—— 填充保持，边框改同色相描边
- AI 连接页的两条行内状态条 —— 填充保持，边框改同色相描边
- 关于 Turna 的品牌头图 —— 描边与投影改 `l1Quiet`，**保留**其 teal→clay 品牌渐变（那是身份表达，不是玻璃效果）

**投影只给真正成面的大面板与品牌头图**；40px 高的行内元素与网格控件不加投影 —— 那只会变成噪点。

范围外的 `glassBorder` 用法（胶囊导航、SnackBar、顶部统计条、AI sheet 控件、Play 弹窗、课程底部弹层）**一律不动**：它们是浮起 chrome，正是 ADR 0062 §范围外 明确保留 `glassBorder` 的用途。

### 5. 深色分支的投影必须按档位取值

原实现里 `glassShadow` 的**深色分支**写死了两层黑投影（0.30 / 0.18），只有浅色分支读档位参数。不改这一处，`l1Quiet` 在深色下拿到的仍是 `l1Subtle` 那副投影，弱化只做了一半。

因此 `_GlassSpec` 增加 `darkNearAlpha` / `darkFarAlpha` 两个字段：既有三档填与当前写死值完全相同的 `0.18` / `0.30`（输出逐像素不变），`l1Quiet` 填 `0.07` / `0.12`。

## 理由

### 为什么不是「直接调 l1Subtle 参数」

`l1Subtle` 是跨域公共色阶。本次要解决的是「设置域深层页太像塑料片」，不是「全 app 的淡彩卡都太浓」。调公共档会把词典、复习进度、错题列表等页面一起拖下水 —— 那些页面当前的密度与观感并没有被反馈为问题。

分档的代价是层级表多一行，收益是**改动半径可控**：本批次只影响设置树。

### 为什么淡彩不能降

见 §2。这是实测记录，不是推测。中性灰 accent 在白底上的可见性本来就薄，把「弱化」做成「降浓度」会直接抹掉卡片边界 —— 视觉上是更弱，但信息上是更差。

### 为什么落地页不弱化

落地页的视觉语言是「品牌渐变 + 玻璃导航组」，靠对比建立层级。若落地页与它的子页长得一样，层级就塌了。落地页是导航，深页是工作区 —— 两者的材质强度本就该不同。

### 为什么参数表要公开

`GlassLevel` 是公开枚举。若参数表私有，「弱化档只削高光与投影、不动淡彩」这类约定就只能靠肉眼比对渲染结果，守不住。公开后契约测试可以直接断言数值关系（见 `test/views/widgets/glass_tokens_test.dart` 的「弱化档 l1Quiet」组）。

## 影响面

- `lib/core/theme.dart`：`GlassLevel` 增 `l1Quiet`；`GlassSpec` 公开并增 `darkNearAlpha` / `darkFarAlpha`；`glassShadow` 深色分支改读档位参数；`glassSpec(level)` 公开为参数表读取入口。
- `lib/views/settings/widgets/primitives/settings_section.dart`：`SettingsCard` 增 `level` 参数，默认 `l1Quiet`。
- `lib/views/settings/settings_page.dart`：落地页两处显式保留 `l1Subtle`。
- 设置树深层页面各自的散落玻璃调用改用 `l1Quiet`；AI 连接页 4 处 + 关于页头图 1 处白描边收口为二代描边。
- `test/views/widgets/glass_tokens_test.dart`：对比度组纳入 `l1Quiet`；新增「弱化档 l1Quiet」契约组。
- golden：`settings_reminder_light/dark` 需重录（`SettingsCard` 换档）。

## 范围外

- **不动 `L1` / `L2` / `L3` 三档参数**，不动设置域以外任何 `glassBorder` 用法。
- **不改 `softTint` 语义** —— 它是「着色平涂」，与玻璃是两条线。
- **不降 `SettingsTile` / `SettingsStatusPill` / `SettingsInfoCard` / `SettingsFormDropdown` / `TurnaChoiceCard` 的浓度** —— 这些是无渐变、无高光、无投影的平涂控件，不属玻璃材质，无可弱化。
- **不推广到设置域以外的其它长列表页**（词典、复习进度、错题列表等）—— 新档已就位，推广属独立批次。
- **`tool/gui` 不参与** —— 它是创作者桌面工具，不消费玻璃材质层（ADR 0062 §范围外）。
- **排版 / 字号 / 间距不做** —— ADR 0033 §明确不做 #6 的边界不变。
