# ADR 0071 — 复习课随机题池与课内错题权重

> 状态：已接受 ｜ 日期：2026-11-07
>
> 真源：`lib/domain/course/review_policy.dart`、`lib/application/review/review_lesson_sampler.dart`

## 背景

静态 `review` 课每次按原顺序播放全部题目，容易变成刷卡。Phase Two 要求一课准备较大题池，每次抽取大部分，混合题型，并让课内错误较多的题型多出现；这套权重不应和记忆卡排期耦合。

## 决策

1. `LessonContent.reviewPolicy` 是显式 opt-in：`minItems`、`maxItems` 和可选 `typeWeights`。没有该字段的存量复习课保持原顺序、全量播放。
2. 首期只支持平铺 `stages` 作为题池，不与 `subLessons` / `listeningPhases` 混用。题池仅含可作答的普通课程题型，排除展示卡和导入记忆卡。
3. 每次课时装载先随机确定题数，再按权重无放回抽取并混排。场内撤销、重置和结算不重抽；下一次装载才形成新场次。
4. 单题权重 = 作者基础权重 × `1 + min(该题型课内错题数, 3)`。基础权重缺省为 1，因此错题加权最高为 4 倍；无错题时使用作者配比。
5. 错误信号只读当前语言 `MistakeProvider` 的 Interaction 快照。错题被重写清除或超出既有日志生命周期后，权重影响随之消失；不新建学习历史，不读 FSRS 到期状态。
6. 抽取后保留原 Interaction ID，课程完成、错题、统计和复习状态仍属于原题与原 Lesson。

## 理由

无放回抽样保证一场不重复；题型级错题加权提供足够弱的自适应信号，同时避免引入另一套排期系统。显式策略和 capped boost 分别保护存量内容与题型多样性。

## 边界

- 本轮只准备引擎、校验、作者工具和测试 fixture，不新增正式复习课。
- 不做按单词 FSRS 调度、跨课程权重或长期掌握度模型。
- AI 练习生成不自动获得该策略，未来接入需单独评审。
