# ADR 0069 — 课程网页目录、草稿预览与反馈修订

> **Status**: Accepted ｜ **Date**: 2026-11-06
>
> 关联：[ADR 0032](./0032-about-page-tool-gui-content.md)（创作者工具不进 App）、[ADR 0054](./0054-ai-practice-library.md)（section JSON 契约）

## 决策

### 1. 网页先于 App 导入，不新增云端 CMS

- 已有课程目录可以直接发布成网页课程目录；AI 生成或人工编辑的内容在保存为课程文件后，可显式调用同一个 `publish-course` hook。只有作者明确执行现有“导入课程”动作时才进入 App 课程内容。
- 单节 section 草稿也可先发布为静态网页，审阅题目与答案、收集反馈、产生新修订。网页预览是 `tool/gui` 的作者工作流，不写 `course.db`，不替代本地教师试做。
- 不引入账号、团队协作 CMS、数据库服务器或前端框架。VPS 只保存课程清单、section 修订与反馈；AI 配置、模型调用、diff 确认和导入均留在本地。
- 发布 hook 是可重复执行的显式命令，不在模型完成时静默上传，也不建立正式课程 OTA 发布关系。

### 2. 共用课程文件与 section 契约

- 整门发布读取课程 `index.json` 的章节顺序与文件引用，并把课程级 `vocab.json` 补入预览副本；工坊与整门课程规划继续产出同一份 section JSON，网页展开器不复制生成器。
- 空章节保留在课程目录中并标记“待施工”，不创建坏预览；非空内容在任何远端写入前完成可读性预检。section 路径必须留在课程目录内，索引 id 必须与文件 id 一致。
- 服务使用 Python 标准库，按课时展示静态题目。不追求 App 交互判分、音频/图片资源包或原卡脚本保真；课程文本和草稿 HTML 一律转义。
- 可读但仍有校验警告的草稿允许粗预览；应用 AI 修订时重新校验，导入课程仍走原有校验、合并预览和 Undo。

### 3. SSH 是管理面，课程目录与私密链接是两种审阅面

- 本地发布和反馈导出复用 `ssh turna`，整门课程通过一次 SSH stdin 调用传输。服务器不提供公开上传/改课 API，也不在 VPS 保存 SSH 或 AI 凭据。
- `/course-preview/` 只列出作者通过 `publish-course` 明确发布的课程；课程使用稳定 course id。单节 `publish` 仍使用随机不可枚举链接，不进入课程目录。
- 课程目录不是身份认证。获得课程地址或私密链接即可查看与留言，因此只发布非敏感课程内容；页面标记 noindex、禁止缓存与嵌入，并限制反馈大小和频率。
- 课程清单保存稳定的 `section id → preview id` 映射。重复发布复用链接，同一 preview id 追加不可变修订，相同内容不新增版本；从课程移除章节不删除旧预览或反馈。
- 反馈记录修订号、稳定题目路径和题目快照，旧链接页面在新版后仍能提交可追溯意见。

### 4. 反馈必须经本地确认才改稿

- 本地拉取留言后复用现有 correction prompt / request 与 diff UI；取消、校验失败或保存失败均不覆盖当前草稿。
- “应用反馈并重新发布”先保存草稿，再更新同一 URL；只有发布成功才把选中的反馈标记为已处理。服务器不自动调用 AI、不自动改课。
- 部署复用 `turnalangua.xyz/course-preview/`，仅监听本机端口，经现有 Caddy 反代。配置候选验证、服务健康检查和失败恢复是部署的必要部分。

## 理由

- 直接把生成物写进课程或 App，会把“题目是否可教”的审阅成本推迟到导入之后；整门课程目录让已有内容无需重复操作，轻量网页让非技术审阅者先看题，再决定是否修改。
- 公开上传 API、账号系统和云数据库会扩大安全与维护面，而 SSH 已能满足单作者发布和取回反馈。显式 hook 也避免模型生成成功后意外公开内容。
- 稳定课程映射与不可变修订同时满足“整门重复发布”和“旧留言可追溯”；发布成功才结案则避免本地已修、线上未更新时丢反馈。

## 影响与边界

- 课程目录和私密链接都不是强身份认证，不能承载教材原文、学习者个人信息或其他敏感材料。
- 这是一套作者侧预览服务，不改变 App 的本地优先、无云后端产品口径。
- 操作契约与运维位置见 [`../../tool/gui/docs/course-web-preview.md`](../../tool/gui/docs/course-web-preview.md)。
