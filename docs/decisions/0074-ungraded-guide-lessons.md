# ADR 0074 — 无判分页式导览课

> 状态：已接受 ｜ 日期：2026-11-19
>
> 真源：`lib/domain/course/guide_page.dart`、`lib/views/lesson/components/guide_session_body.dart`

## 背景

课程首节需要把语言认识从词汇训练中独立出来：学习者先读几页介绍，通过点读、分类、词尾组合和语序开关建立印象，而不是回答语言知识测验。复用 `showWord` 会把每次确认记为正确作答，并进入正确率、错题、SRS 与奖励结算，不符合这一目标。

## 决策

1. 新增 `LessonTemplate.guide` 与 `LessonContent.pages`。页面由数据驱动的 `GuideBlock` 组成，不构造 `Interaction`，也不混入答题阶段或子课。
2. 导览复用课程加载、课程树、课时壳和 TTS，以页码推进。上一页、下一页和重读不影响完成记录，互动始终可以跳过。
3. 完成仅写入课程完成状态，不发放答题或完美课奖励，不写正确率、错题、学习统计或词汇／语法 SRS。
4. 通用内容块覆盖文字、点读词卡、分类、词尾构建和语序探索。分类的错误放置只显示作者提示，不计分；拖拽同时提供点选路径。
5. `terms.wordId` 仅用于资源引用追踪，不产生调度副作用。Dart、Python 和桌面作者工具共同识别 `pages`，校验器拒绝在导览中夹带题目。

## 理由

页式内容模型把“阅读与探索”与“练习与判分”分开，避免用一组特例把展示卡伪装成无题课程。数据驱动内容块同时保留其他语言和其他导览主题的复用空间。

## 边界

- 导览不适合需要检索练习、掌握检测或间隔重复的内容；这些仍使用既有题型与课型。
- 首版作者工具提供页面结构预览与无损保存，不为每种内容块提供专用可视化编辑器。
- 首例为第 0 单元六页土耳其语认识课；元音和谐分类是该通用组件的首个正式用例。
