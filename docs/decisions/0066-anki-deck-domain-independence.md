# ADR 0066 — 记忆卡域独立于语言课程域

> 状态：已接受 ｜日期：2026-11-03
>
> 前置：ADR 0037（Anki 课程与复习大一统）、ADR 0042 / 0043（staging-first 官方导入与单一事实源）、ADR 0057（记忆卡适配方案）
>
> 关联：[app-design-refresh-plan.md](../app-design-refresh-plan.md)（全 App 版面重设计，本决定来自其评审）

## 背景

ADR 0037 把 Anki 牌组统一进「课程」概念，数据与复习内核因此共享一套底座（`ReviewItem`、正式会话、单一事实源）。界面与信息架构也随之交织：语言课程的课程管理页把 Anki 牌组列进「我的课程」、「添加课程」区放着「从 Anki 导入」卡、导入完成动作「立即学习」会把当前课程切换成 Anki 牌组、练习中心在 Anki 课程域下隐藏语言队列。

对用户而言这是两种心智模型：语言课程是结构化学习路径，记忆卡是自带牌组、按 Anki 原版方式使用的工具。混排让课程管理变复杂，也让语言课程入口出现与其无关的概念。全 App 版面重设计评审中明确了产品口径：**记忆卡完全独立于土耳其语（语言课程）之外，功能设计保持原版，不加入语言课程。**

## 决策

记忆卡（Anki 牌组的导入、管理、复习、统计、修复）在**界面与信息架构层面是独立域**。底层继续复用 ADR 0037 的统一底座（数据、引擎、正式会话、来源统计）；本决定只收回「Anki 即课程」的界面口径。

### 1. 功能保持原版

- 导入管线不变：五步向导（选文件 → 解析 → 预览 → 提交 → 完成）、staging-first（ADR 0042）、适配方案与三档保真（ADR 0057）、中断恢复。
- Anki 式功能集不变：牌组列表与排序、到期排期、原卡 HTML/CSS 保真渲染、二档评分、牌组统计、卡牌浏览器、修复中心。
- 记忆卡域的界面翻新只动视觉外壳（布局、材质、文案），不动流程、判定与保真契约。

### 2. 语言课程域不出现记忆卡

- 课程管理只管语言课程（内置语言 + `.turnapack`）；「我的课程」列表不包含 Anki 牌组，「添加课程」区不放 Anki 导入卡。
- 课程树、课时与练习的语言队列（单词 / 语法 / 错题 / 弱词 / 词典）永远只含语言课程内容。
- 导入完成动作不再切换当前语言课程：「立即学习」改为直接进入该牌组的正式复习，「查看牌组」指向记忆卡中枢。

### 3. 记忆卡域自有入口

- 记忆卡中枢（现 `anki_review_screen` 的翻新版）是域首页：到期总览、牌组列表、导入入口。
- 练习任务台在有牌组时显示一行独立的「记忆卡」队列（聚合到期数），点击进入记忆卡域；语言队列不因记忆卡存在而隐藏。
- 学习洞察 / 来源详情继续可展示记忆卡来源的统计（数据层统一保留），其「开始复习」跳转记忆卡域。

## 范围外

- 不改数据与引擎层：课程目录中 Anki 源的存储结构、`ReviewItem`、正式会话宿主、`FormalReviewLauncher` 契约不动（ADR 0043 / 0050）。
- 不改鸿蒙 Official Anki 口径（ADR 0050）与诊断守卫。
- 不重命名内部契约（`anki-` 前缀、协议键、表名）——那是独立议题（AGENTS §7.2）。

## 影响面

- 课程管理页：移除 Anki 牌组行与「从 Anki 导入」卡（P3 / P4 重构时落地）。
- 导入向导：入口收敛到记忆卡中枢；完成步动作改指记忆卡域。
- 练习中心：「Anki 课程域」界面分支（`PlayReviewEligibility.isAnkiScope` 驱动的队列裁剪）退役，改为常驻语言队列 + 条件记忆卡行。
- 学习 Tab 顶栏到期聚合中的记忆卡分量，并入记忆卡域与练习任务台的记忆卡行。
- 设计文档：[app-design-refresh-plan.md](../app-design-refresh-plan.md) 实施边界、`docs/design-refresh/` 覆盖表与线框按本决定更新。
