# ADR 0068 — L0 环境天光与真毛玻璃档

> 状态：已接受 ｜日期：2026-11-04
>
> 前置：ADR 0062（彩色玻璃材质：白纸上的淡彩玻璃）、ADR 0065（降彩度与表面角色分离）
>
> 真源：`lib/core/theme.dart`（`ambientLights` / `AmbientLight` / `GlassLevel.l2Frost` / `frostSigma` / `glassFrostFill`）、`lib/views/widgets/ambient_backdrop.dart`、`lib/views/widgets/glass_surface.dart`
>
> 关联：**部分取代** ADR 0062 §1 的 L0 行与「依赖 `BackdropFilter`：否」这一条；ADR 0062 §2 的参数表、ADR 0065 的表面角色分工全部不变

## 背景

ADR 0062 把画布定成纯白，理由写得很明确：

> 背景是白的，糊了还是白。

这条推理对**卡片填充**成立 —— 不透明淡彩压在纯白上，`BackdropFilter` 确实只烧 GPU 不出效果，所以标准档一律不用模糊。

但它顺带取消了一件事：**空间**。画布纯白 + 卡片淡彩，屏幕上没有光源方位、没有前后关系。全 App 逐页重设计（P3 / P4）完成后，这个问题在最空的两个页面上变得显眼：

- 课时作答页：题面卡以下约 55% 屏高是一整片平白（`dist/design-refresh/walkthrough-q1.png`），读作"没渲染完"而不是"留白"。
- 课程主页：只有两张纸面卡，其余全是白，包豪斯的几何骨架没有落点。

同时 `AmbientBackdrop` 这个 L0 语义锚点在 ADR 0062 之后退化成纯色层，**并且没有任何调用点** —— 一个没有被接线的 L0 层本身就是「这套系统还没做透」的证据。

## 决策

### 1. L0：白 + 三片极淡天光，不是"有色背景"

画布仍以白（深色为近黑）为底，在其上叠三片**径向光晕**：

| 位置 | 色相 | 峰值 alpha（浅色） | 半径（相对短边） |
|---|---|---|---|
| 左上 | `brandTeal` | 8.6% | 0.72 |
| 右上 | `warmSand` | 7.0% | 0.68 |
| 底缘 | `anatolianClay` | 7.8% | 0.86 |

三条硬约束，缺一条就会退回 ADR 0062 警告的那个失败态（"被染过的底 + 灰白卡"）：

1. **峰值 alpha ≤ 10%**。超过这个数，卡面 9~19% 的淡彩就失去参照。
2. **光心只落在页面边缘或画布外**，中部三分之一区域必须保持净白。半径收到 0.6~0.86 就是为了让光"集中成角落的一团"，而不是整屏淡染。
3. **高对比 / `GlassMode.off` 时整层为空表**，画布退回纯色。光晕是对比度噪声。

光斑是静态的，不呼吸、不视差、不随滚动位移。整层 `RepaintBoundary` + `IgnorePointer` 隔离，不参与内容重绘与命中测试。

接线范围：主外壳（`HomePage`）、课时作答页（`NewLessonScreen`）、三个长文阅读页（关于 / 隐私 / 透明日志）。

### 2. `GlassLevel.l2Frost`：唯一带实时模糊的档位

新增第六档，与 `l2` 的区别**不是更浓，而是填充不实**：

| | 填充 | 模糊 | 顶部受光边 | 用在哪 |
|---|---|---|---|---|
| `l2` | 不透明淡彩 | 无 | 无 | 一般浮起面 |
| `l2Frost` | 半透明淡彩（`frostOpacity` 默认 0.72） | `sigma = 14` | 1px 白 62% 渐变短边 | 一屏里**唯一的主体卡** |

`glassFrostFill` 把彩色罩在半透明白（深色下是半透明暗面）上，背后那层天光才能被糊开再透上来。装饰层也一并被糊 —— 这是刻意的：毛玻璃的边缘本来就软。

使用约束：

- **每页至多两张**。每处 `BackdropFilter` 都是一次全屏采样。
- **不得用于列表行**。长列表铺模糊会直接掉帧，且视觉上糊成一片。
- **不得给 `l1` / `l1Subtle` / `l1Quiet` 加模糊**。它们的填充是不透明的，糊了也看不见 —— 这正是 ADR 0062 §1 唯一仍然完全正确的部分。

首个落地：个人页头卡（`AccountWidget`）。它原本就是半透明渐变（teal 12% + sky 18%）但没有模糊，读作"半透明贴纸"；补上 `BackdropFilter` 后才是玻璃。

### 3. 不变的部分

- 淡彩浓度、白高光预混、同色相双层投影、积色描边 —— ADR 0062 §2 与 ADR 0065 的参数**一个都没动**。
- `flatPaperDecoration` 与「一页三种表面」的角色分工不变。
- 底部胶囊导航与 SnackBar 的磨砂仍是独立实现，不走 `l2Frost`（它们是 chrome，不是内容卡）。

## 代价

- 每屏多 3 个 `RadialGradient` 绘制。用 `RepaintBoundary` 隔离后是常量成本，不随滚动增长。
- `l2Frost` 每页 ≤2 次全屏模糊采样。真机上单张 400×800 的 `sigma 14` 约 1~2ms，可接受；一旦某页需要第三张，说明这一页的主体不唯一，应该先调整版式而不是加档位。

## 已知边界

**在白纸上，毛玻璃本身读不出"玻璃"。** 只有背后确实有可辨内容（天光、几何图形、图片、其他卡片）时，模糊才成立。所以这条 ADR 只解决"有没有东西可糊"；**几何图形铺开是它的前置条件之一**，而不是它的装饰。

## 范围外

- 不改品牌 hex、字号、间距、圆角。
- 不做动态光斑 / 视差 / 实时折射 / 着色器。
- 不新增暗色主题策略（深色沿用同一套，只是浓度不同）。

## 补记（2026-11-04）：几何铺开与它的尺度天花板

上面「已知边界」说过「几何图形铺开是毛玻璃的前置条件」。这一轮把几何铺到了
四个主页面，并实测出这条论断的**适用尺度**——它在页面尺度成立，在卡片尺度不成立。

### 新增的三个页级形态

`TurnaGeometryKind` 原有四种（`ripples` / `journey` / `connection` /
`achievement`）都在方框**内部**，是徽章尺度。补三种页级形态：

| 形态 | 读作 | 放法 |
|---|---|---|
| `arch` | 半圆拱：直径压在方框下沿并越出两端 | 底缘（课程页） |
| `diagonalCut` | 斜切留白：三角面切掉一个角，斜边一条线 | 页角（练习台） |
| `ring` | 单环：环心偏右，右缘被切 | 卡片右缘（个人页动作簇） |

三者都**刻意画到方框之外**，靠被屏幕或卡片边缘切掉才成立——放进方框中央会读成贴纸。
配套 `TurnaGeometryBackdrop`：贴角、`IgnorePointer`、`RepaintBoundary`、
`GlassMode.off` 时不画。

### 硬约束：14 sigma 吃掉了卡片尺度的几何

实测结论，写在这里免得下一轮再试一次：

- `sigma = 14` 会把 **10px 宽的线整条抹平**，再乘 `frostOpacity 0.72` 的遮罩后彻底不可见。
- 要让一个图形**透过**毛玻璃读得出来，它的特征宽度得 ≥ 30px（≥ 2σ）。
- 个人页身份卡只有约 104px 高，放不下 30px 带宽的环；放大到 168 又会被卡边切掉三条边，
  变成一块色斑。

所以个人页的环**印在模糊层之上、正文之下**——它是"印在玻璃上的图形"，不是
"玻璃后面的图形"。这不违背「几何是模糊的前置条件」：那条说的是**页面尺度**
（课时页 55% 的空白、练习台的标题带、课程页的地面带），页面尺度的形确实给
毛玻璃提供了可糊的内容；卡片尺度上则反过来，几何必须走到模糊层前面。

### 四个落点

| 页面 | 形态 | 位置 | 为什么只能在这里 |
|---|---|---|---|
| 课程 R02 | `arch` | 视口底部，继续条之上 | 旅程行是不透明纸面（ADR 0065），拱只能出现在"列表收尾 → 继续条"那条带 |
| 练习 R03 | `diagonalCut` | 右上角，压标题带 | 主卡以下全是方块砖，唯一露底色的是标题带 |
| 个人 R15 | `ring` | 身份卡内右侧，动作簇的光环 | 卡以下全是纸面行族，页级大形会从行缝里漏出来；环缩进卡内由圆角裁切 |
| 设置 R16 | `connection` | 右上角，压标题带 | 同练习；顺带修掉一处**既有缺陷**：落地页 `Scaffold` 自铺不透明 `scaffoldBg`，把 L0 天光整个盖住了，是四个 Tab 里唯一没有环境光的一页 |

### 不变量

几何浓度由 `intensity` 相乘（页级默认 0.8~0.86），**不改画笔里的 alpha 常数**——
徽章尺度的五个既有消费点（启动 / 完成 / 空态 / 分享卡 / 课时弹层）亮度因此零变化。

## 补记二（2026-11-05）：课时页那 47% 的空白，不是几何的活

上一节说「课时页题面以下的空区靠底缘陶土余温兜住」。补了天光之后仍然空着近半屏，
但**不能用几何填**——P1 §逐族线框已经定了「题面无装饰图形（评审决定）」。这一轮
换了个方向：不是往空白里加东西，而是让空白变成对称的页边。

### 根因是布局，不是装饰

`ShowWordRenderer` 的读卡外面本来就写着 `Center`，意图明确是要垂直居中。它一直
没生效：滚动视图给孩子的最大高度是无穷大，`Center` 只能收缩到内容高度。实测
400×800 下卡片贴在阶段行下面，底边落在 53% 处，下面 47% 全空。

修法在 `PracticeSessionBody`：读卡（`autoAdvance`，没有底栏）给滚动内容一个
「至少一屏」的下限（`ConstrainedBox(minHeight: 视口 - 16)`），`Center` 才成立。
内容超一屏时下限不起作用，滚动行为与改动前逐像素一致。

### 只给读卡做，不给作答卡做

作答卡提交后会在卡下长出解析。若也居中，每提交一次整张卡就向上跳半个增量
——作答页最不能有的就是「我按了核对，题目跑了」。读卡没有这种增长，位移风险为零。
这条边界写进了 `practice_session_body.dart` 的注释与
`test/views/lesson/practice_session_body_layout_test.dart` 的三条契约
（读卡居中 / 作答卡贴顶 / 超屏仍可滚）。

### 顺带纠正一条我上一轮的误判

上一轮说「顶栏仍是实色，底栏是磨砂，上下材质语言不一致」。复核后不成立：
`LightTopBar` 与 `SessionProgressBand` 都是**透明**的（画布即顶栏），课时页那条
看起来有底的横带是 `LessonStageBanner` 的 teal 6% 上下文底，不是顶栏。真正有底的
只有 `SessionActionBand`（纸面动作带 + 顶部发丝线），它和底部胶囊导航分属会话壳
与根壳两套骨架，本来就不该同材质。
