# ADR 0001: TTS Language Code for Swahili

## Status

**Superseded by [ADR 0020](./0020-swahili-to-turkish-pivot.md)** — the project
pivoted from Swahili to Turkish; the TTS language code is now `'tr'`. This ADR
is kept as a historical record.

Accepted (2026-07-09)

## Context

Varnamala is a Swahili-first language learning app. However, the current bundled vocabulary (`assets/courses/swahili/vocab.json`) still contains Kannada placeholder words while real Swahili content is being prepared.

The TTS language code had been set to `'kn'` so that the placeholder Kannada words could be pronounced by the device TTS engine. At the same time, the course index (`assets/courses/swahili/index.json`) already declared the course language as `"sw"`, creating a mixed signal.

`future2.md` Phase 10 requires a single, explicit decision: use `'sw'` or keep `'kn'`. The two codes must not be mixed.

## Decision

Use **`'sw'`** as the TTS language code for `TargetLanguage.swahili`.

`lib/application/language_provider.dart` now returns `'sw'` from `ttsLanguageCode`.

## Consequences

- The app is consistent with its stated target language (`"sw"` in `index.json`, `vocab.json`, and `expressions.json`).
- Until the Kannada placeholder vocabulary is replaced with real Swahili content, the device TTS will attempt to pronounce Kannada words using a Swahili voice. For words the Swahili voice does not recognize, it will likely fall back to spelling out the letters.
- The offline-audio fallback path in `AudioController.speakWord` is unchanged. When real Swahili audio assets are added to `WordEntry.audioAsset` / `Expression.audioAsset`, they will take precedence over TTS automatically.
- No new audio files or course content are generated by this decision.

## Alternatives Considered

- **Keep `'kn'`** — would preserve pronunciation of the placeholder Kannada words, but would leak implementation detail into runtime behavior and conflict with the Swahili-first positioning of the app.
