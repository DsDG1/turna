# ADR 0058 — 内置课程统一选择内容来源

> 状态：Accepted ｜ 日期：2026-10-30

## 决策

- 内置课程 JSON 统一经过 `CourseContentSource`：候选为 manifest 指定的打包目录和应用文档目录下的 `content_updates/<language>/`。只处理 manifest 中的内置语言，外部课程仍走 `.turnapack` 的独立导入契约。
- 来源按 `(index.version, expressions.version)` 依次比较，先比较 index，再比较 expressions；同版采用内置内容。更新目录缺失或校验失败时回落内置内容。
- 下载内容在选中前完整解析并复用 `validateCourse`；选中后缓存一套 JSON 快照。缺文件时拒绝该更新，不逐文件回落 assets，避免组成从未发布过的混合课程。
- `DatabaseSeeder` 和课程等级补全读取同一来源。每门内置课程的清表、写入、版本记录在同一个数据库事务中完成，失败保留原有课程和版本。
- 运行中应用更新，经 `CourseProvider.refreshBuiltinContent` 重选来源、按版本重播种、失效词汇与课程缓存并刷新页面；进度沿用 [ADR 0002](./0002-content-replacement-progress-policy.md) 的保留／重置选择。与课程切换串行，学习活动或远端备份期间不应用更新。

## 理由

课程运行时主体已经存入数据库。仅替换 `CourseLoader` 的 assets 读取无法更新数据库中的课时、词表和表达，因此来源选择必须进入播种器。

无条件优先下载目录会让较新的应用安装包继续读取旧下载内容；只比较 index 又会遗漏 expressions 单独升级。采用复合版本的有序比较，同时保留现有数据库版本键格式。

文件级 fallback 可能让新版 index 引用旧课时，或让旧词表配上新版题目。整套校验、快照读取与数据库事务分别约束来源一致性和写入完整性。

## 边界

- 此接缝负责读取本地完整课程，不负责下载、校验和、清单签名、发布或更新入口。
- 更新只承载数据，当前读取限 JSON；新媒体的本地路径解析需单独接入。
- 后续下载器必须先在临时目录完成校验，再切换完整目录；切换失败前保留旧版，并处理进程中断恢复。不得先删除唯一可用的旧目录再尝试改名。
- 手动放入课程目录用于开发时，应在 app 停止期间写入完整内容，启动后复用现有版本驱动的重播种与进度提示。
