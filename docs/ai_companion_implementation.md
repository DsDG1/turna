# AI 伴学实现说明

本文件记录桌面《AI伴学功能优化与丰富化实施计划》在客户端中的落地边界，供后续维护、验收和平台适配使用。

## 已落地的闭环

1. `LearningEvidence` 统一承接旧错题、SRS、课内提示和 AI 会话反馈，并用透明规则生成知识点掌握度。
2. `LearnerProfileSnapshot` 生成结构化画像及最小化 Prompt 摘要；关闭个性化后不发送画像、旧会话或错题。
3. 本地提示状态机控制 `conceptCue → ruleCue → contrastCue → partialReveal → fullExplain → verify`，避免模型自行越级。
4. 会话、消息、诊断、计划、笔记和请求指标写入 Drift；会话支持恢复、重命名、删除、纯文本导出和历史摘要裁剪。
5. 本地诊断引擎只基于证据给出弱项、置信度和趋势，并可生成 5 / 10 / 20 / 30 分钟计划。
6. 课程检索器返回经过白名单校验的 Top-K 来源；未配置模型时仍可用本地课程片段答疑。
7. 知识笔记保留旧收藏正文和时间，支持状态、7 天复习、离线验证题及可编辑的 Anki TSV 预览。
8. 情景对话支持 A1 / A2 / B1、纠错节奏、成功条件、结束复盘和可用平台上的 TTS。

## 安全与可观测性

- API Key 不再写入普通偏好、配置 JSON、日志、导出或缓存；旧明文 Key 验证迁移成功后才删除。
- 学习者敏感缓存仅存内存；设置页可分别清除 AI 学习数据和凭据。
- 请求带功能名、Prompt 版本、幂等键、输出上限、超时和一次安全重试，并记录延迟、Token、结果及缓存命中。
- 每日软 / 硬预算由 `AiBudgetManager` 统一判断。

## 平台边界

- Android / iOS / macOS / Windows / Linux 使用 `flutter_secure_storage` 可用实现；Web 及缺少原生安全存储插件的平台仅会话内保留 Key，并在设置页提示。
- 当前 Web 启动路径本身不提供 Drift 课程库，因此课程检索和会话持久化按现有平台能力降级。
- 语音转文字、OCR 和图片场景任务仍属于计划中的后续平台试验；文本伴学和 TTS 不依赖这些能力。
- 不提供没有可靠评分模型支撑的口音或音素分数。

## 自动化验收

- AI 专项测试覆盖安全迁移、会话恢复、证据与掌握度、分层提示、诊断计划、引用校验、匿名 Prompt、清除一致性、预算指标和离线评测样本。
- 离线评测样本位于 `test/fixtures/ai_eval/`，包含 40 条语法问答、30 条批改、30 条错因、20 组提示、20 组诊断、20 组检索及对抗输入。
- 数据库 Schema 当前为 v16；迁移测试覆盖旧版本升级和未来版本拒绝降级。
