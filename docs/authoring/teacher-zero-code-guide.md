# 零代码老师使用指南

> 本文档面向**不懂代码的语言老师**，给出从拿到程序到独立产出一节合格课程的完整步骤。
> 对应 guiplan §15 教师视图的目标：全程不接触 id / path / version / JSON 概念。

---

## 前置准备（只需做一次）

### 1. 安装程序

老师会收到一个 `turna-gui.exe`（Windows）或对应可执行文件，**双击即可运行**，无需安装 Python 或任何开发工具。

> 如果收到的是源码版本，技术人员需先按 [`tool/gui/README.md`](../tool/gui/README.md) 打包。

### 2. 准备课程目录

程序打开的是一个**课程文件夹**（例如 `turkish`）。老师应向技术人员索取一份最新的课程目录副本，放在自己电脑上任意位置（如桌面 `我的课程/turkish/`）。

> ⚠️ 不要直接编辑团队共享目录，建议每次复制一份副本操作，发布前再合并。

---

## 核心工作流：产出一节 intro 课

intro 课是「认识新词」课型，一节典型的 intro 课包含：展示新词 → 选择释义 → 填空巩固。以下步骤以新增一节 intro 课为例。

### 第 1 步：打开课程

1. 双击 `turna-gui.exe`
2. 点工具栏「打开」按钮
3. 在弹出的文件夹选择器中，选中课程目录（如 `turkish/`）并确认
4. 左侧出现课程树：Section → Unit → Lesson 三级

### 第 2 步：定位要新增课的位置

1. 在左侧树中找到目标 Section（如「Section 1」），点击展开
2. 找到目标 Unit（如「Unit 1」），点击展开
3. **右键点击该 Unit** → 选择「新增 Lesson」

> 程序会自动生成一个唯一编号（id），老师无需关心，只需填写课程名称。

### 第 3 步：填写课程基本信息

右侧面板出现课程元数据表单：

| 字段 | 填什么 | 例子 |
|------|--------|------|
| 名称 | 给这节课起个名字 | 「问候语」 |
| 描述 | 一句话说明这节课学什么 | 「学习基础土耳其语问候」 |
| 先修 | 勾选学生必须先完成的课（同 Unit 内其他课） | 勾选「打招呼」 |

> 「先修」是多选勾选框，只显示同 Unit 内的其他课，勾选表示「学生必须先学完这些课才能学这节」。

### 第 4 步：选择课型

在课程内容编辑区，选择课型模板：**intro（认识新词）**。

> 程序会按 intro 模板生成一个默认结构（含子课与展示阶段），老师只需往里填内容。

### 第 5 步：添加新词到词库

intro 课需要引用词库里的词。先确保要教的词已在词库中：

1. 点工具栏「资源」按钮
2. 切换到「词库」标签页
3. 点「+ 添加行」，在表格中填写：
   - 词（土耳其语）：如 `Günaydın`
   - 翻译（中文/英文）：如 `早上好`
   - 发音：如 `gu-nay-din`（可选）
   - 标签：如 `问候`（从白名单选）
4. 关闭资源对话框
5. 点工具栏「保存」

> 词库里的「编号」（如 `w-gunaydin`）由程序自动生成，老师只需记住词本身。

### 第 6 步：编排课程内容

回到刚新建的 Lesson，在内容编辑区按子课组织题目：

**子课 1：认识新词**
- 题型选「展示新词」
- 从词库下拉框选一个词（如 `Günaydın - 早上好`）

**子课 2：选择释义**
- 题型选「选择题」
- 写题干（如「Günaydın 是什么意思？」）
- 添加 2-4 个选项，点正确选项前的圆圈设为正确答案

**子课 3：填空巩固**
- 题型选「填空」
- 写句子并留空（如「早上好，___ !」）
- 填正确答案 `Günaydın`

> 每种题型一张卡片，所见即所得。改完点「保存」。

### 第 7 步：检查与发布

1. 点工具栏「发布」按钮，弹出发布对话框
2. 对话框自动显示：
   - **本次改动**：哪些内容改了（如「Section/Unit/Lesson 结构：有改动」）
   - **版本号变更**：如「index.json: 7 -> 8」（可取消勾选）
   - **音频资源核对**：如果有听力题，列出缺失的音频 ⚠️
   - **id 集变更**：新增/删除了哪些词、课
   - **校验状态**：✓ 通过 或 ✗ 失败
3. 如果校验失败（红色 ✗）：
   - 对话框会列出错误，如「这道题引用了不存在的词」
   - 按「取消」返回修复，修好再点「发布」
4. 校验通过后，点「确认发布」
5. 状态栏显示「发布成功」

> 「发布」= 保存 + 自动 bump 版本号 + 校验。版本号是给程序识别「内容有更新」用的，老师看到「7 -> 8」确认即可，无需理解含义。

## 常见错误与处理

| 错误提示 | 原因 | 怎么修 |
|---------|------|--------|
| 「这道题引用了不存在的词」 | 题目选了一个已删除的词 | 打开题目，从词库下拉重新选一个现有词 |
| 「重复的课程编号」 | 两节课用了相同编号 | 老师一般不会遇到（编号自动生成）；若遇到，删掉重复的那节重新新增 |
| 「听力课的题没有音频」 | 听力题引用了音频但文件不存在 | 把音频文件放到 `assets/sounds/listening/` 目录，或暂时删掉这道听力题 |
| 「保存失败，已回滚」 | 内容有校验错误 | 程序已自动撤销改动，按错误提示修复后再保存 |

## 进阶：用 CSV 批量编辑词库

如果一次性要加很多词，可以在表格里逐行加，也可以用 CSV 批量导入：

1. 点「资源」→「词库」标签 →「导出 CSV」得到当前词库表格
2. 用 Excel/WPS 打开 CSV，在底部新增行填写：`编号, 词, 翻译, 发音, 音频文件, 标签`
   - 编号以 `w-` 开头（如 `w-yeni`）
   - 标签用逗号分隔（如 `问候,日常`）
3. 保存 CSV
4. 回到程序，「导入 CSV」选择刚编辑的文件
5. 若有错误（如某行词为空）会弹窗提示且不应用；修正后重新导入
6. 点「保存」

> CSV 是「高级功能」，日常少量加词直接用表格更方便。

## 教师视图（已上线）

上述步骤用的是「专家视图」（显示编号、版本号等工程概念）；GUI 现已提供**教师视图**（`tool/gui/src/teacher/`），对零代码老师隐藏编号/版本/路径等工程概念：

- 字段名用教学语言（「词」而非「wordId」、「第 4 单元第 1 课」而非 path）
- 课型向导：选 3 个词 → 自动生成「展示→翻译→填空」3 题
- 实时预览：点「预览本课」可像学生一样做题，自我验证
- 人话报错：「词库里有重复的词『Merhaba』，已在第 12 行」
- 引导式发布：只显示「改了什么 / 缺什么 / 点发布」，看不到 version 字段

老师可在两种视图间切换；日常建课推荐教师视图，专家视图适合精细调试与批量操作。

## 检查清单：一节课是否合格

发布前，老师可对照以下清单自检：

- [ ] 课程有名称和描述
- [ ] 每道题都引用了词库里存在的词（不悬空）
- [ ] 选择题设了正确答案
- [ ] 填空题有正确答案
- [ ] 点「发布」后校验通过（绿色 ✓）
- [ ] 若有听力题，音频文件已就位（发布对话框无 ⚠️）

全部勾选即可发布。程序会自动校验并保存，老师无需担心写出错误数据。
