Varnamala 课程编辑器 GUI · 小白入门指南

这是一份从零开始的使用指南，假设你从来没接触过命令行、JSON、Git，也能照着一步步把一门语言课程做出来。每一步都告诉你「点哪里、看到什么、接下来做什么」。

如果你已经熟悉概念，只想查功能，直接跳到 §6 功能速查表。

本地桌面程序 课程存为 JSON 不联网上传课程内容（AI 功能除外，见 §5）

1它能做什么 / 不能做什么

能做

  • 用图形界面编辑一门语言课程：章节（section）→ 单元（unit）→ 课时（lesson）三级结构。
  • 每节课里放各种题型：选择题、翻译、填空、听写、阅读理解等（共 12 种）。
  • 维护三类资源库：词汇表 / 常用表达 / 语法点，课时里引用它们。
  • 一键校验 + 发布：检查课程有没有错（空字段、悬空引用等），给版本号，生成音频清单。
  • 用 AI 自动生成一整门课，或从一本 Markdown/PDF 教材半自动导入成课程。
  • 撤销/重做、自动保存、深色/浅色主题。

不能做（故意不做的边界）

不做原因
联网同步课程内容课程只存本地 JSON；只有 AI 功能会联网调大模型
替代你审核 AI 输出AI 生成的内容仅供参考，你必须自己核对
OCR / 识别扫描版 PDF教材导入只支持「文本可选中的 PDF」，扫描件请先转成文字
自动发布到应用商店发布只是给课程版本号 + 校验，装到手机仍需走 Flutter 打包流程

2第一次安装与启动

2.1 装运行环境

需要 Python 3.11 或更高。打开命令行（Windows：开始菜单搜 cmd；Mac/Linux：终端），输入：

pip install PySide6 PyPDF2 python-docx
  • PySide6 是图形界面库（必装）。
  • PyPDF2 让你能导入 PDF 教材（可选，不装则 PDF 导入会提示缺依赖）。
  • python-docx 让你能导入 Word 文档（可选）。
💡

装不上？如果是公司/学校网络限制，试试 pip install --user PySide6。Mac 若提示权限，命令前加 python3 -m：python3 -m pip install PySide6。

2.2 启动

在仓库根目录（就是包含 tool/、lib/、assets/ 的那个文件夹）运行：

python -m tool.gui.src.main

启动后会看到一个空白窗口，顶部一排按钮。如果报错「No module named PySide6」，回到 §2.1 确认装好了。

2.3 第一次打开课程

  1. 点顶部菜单按钮 「课程仓库」（写着文件夹图标的下拉）→ 「打开课程目录…」。
  2. 在弹出的文件选择框里，找到仓库里的 assets/courses/turkish/ 文件夹，选中它，点「选择」。
  3. 左边会出现一棵树：Section 1 / Section 2 ...，点开就能看到单元和课时。
💡

没有现成课程？点「课程仓库」→「新建课程目录…」，选个父文件夹、填个名字（如 MySpanish），点「初始化」，会自动生成一套样例课程（默认中教英）并加载进来，你可以直接改。

35 分钟上手：从零做出一节课

这一节带你完整走一遍「打开 → 编辑 → 保存 → 校验」的流程。

第 1 步：打开课程

按 §2.3 打开 assets/courses/turkish/。左边出现课程树。

第 2 步：找到一节课

点开 Section 1 → 点开里面的 Unit → 点一个 Lesson。右边会出现这节课的编辑面板。

第 3 步：改一个词的翻译

  1. 在右侧面板找到这节课引用的词汇（通常在「内容」区）。
  2. 把某个词的「翻译」从 hello 改成 你好。
  3. 改完按 Ctrl+S，或点顶部 「保存」 按钮。

第 4 步：看校验结果

保存时程序会自动跑校验：

  • ✅ 通过：底部状态栏显示「已保存」，没有弹窗。
  • ❌ 有错误：弹窗列出问题（比如「某 lesson 引用了不存在的词汇 id」），并自动回滚到保存前的状态——你的改动还在内存里，改对再保存即可。

第 5 步：撤销

改错了？按 Ctrl+Z 撤销，Ctrl+Shift+Z 或 Ctrl+Y 重做。撤销步数可在「设置」里调（默认很大）。

🎉

恭喜，你已经会基本编辑了。下面是每个区域的详细说明。

整个窗口从上到下、从左到右分成几块：

┌─────────────────────────────────────────────────────────────┐
│ 顶部工具栏:课程仓库 | 保存 | 课程工坊 | 总览 | 资源库 | 发布 | 教师模式 | 设置 │
├──────────────┬──────────────────────────────────────────────┤
│              │                                              │
│  左侧课程树   │            右侧编辑面板                       │
│ Section       │   (选中什么,这里就编辑什么)                    │
│  └ Unit       │                                              │

│              │                                              │
├──────────────┴──────────────────────────────────────────────┤

4.1 顶部工具栏（从左到右）

按钮干什么什么时候用
课程仓库（下拉）新建 / 打开 / 最近打开过的课程目录第一次打开，或切换课程
保存把改动写回 JSON 文件，并自动校验每次改完想存盘
课程工坊一站式创作：教材导入、AI 生成、审校、导入想快速起稿或导入教材（见 §5）
资源（下拉）编辑词汇/表达/语法点，或从 Git 库获取维护资源库（见 §4.4）
发布版本号升级 + 音频清单 + 改动对比课程做完要发布（见 §4.5）
教师模式打开一个独立窗口，逐课时预览教学视图想以老师视角看每节课
设置主题、字体、AI 配置、撤销步数等调整偏好（见 §4.6）
ℹ️

带 (Beta) 的功能会调 AI，消耗 token（见 §5）。第一次点会弹警告，确认后不再重复。

4.2 左侧课程树

  • 三级结构：Section（大阶段，如 A1/B1）→ Unit（单元）→ Lesson（课时）。
  • 点选：选中一个节点，右边显示它的编辑面板。
  • 右键：在节点上右键，可以「新增子节点 / 删除 / AI 编辑此处」。
  • 上下移动：树上方有 ↑ / ↓ 按钮，在同级里调整顺序（不会跨层级，所以不会乱）。
  • 图标/颜色：已学完、有薄弱项、待学的课时会有不同标记。

4.3 右侧编辑面板

选中不同节点，右边显示不同内容：

  • 选中 Section / Unit：显示元数据表单——name（显示名）、description（描述）、prerequisite（前置依赖，勾选框多选，只能选同级的）。
  • 选中 Lesson：显示课时内容编辑器——可以加 sub-lesson（子课）和 stage（阶段），每个阶段里放各种题型（见下）。

课时里的 12 种题型

在阶段里「添加题目」时可选：

题型学生要做什么
多选题（multipleChoice）选正确翻译
翻译（translate）翻译整句
填空（fillBlank）填缺失的词
配对（matchWords）左右配对
听力选择（listening）听音频选词
听写（typeTheWord）听音频打字
阅读选择（readingMCQ）读段落做题
阅读判断（readingTrueFalse）判断对错
阅读简答（readingShortAnswer）写答案
展示词（showWord）认识新词
翻译句（translateSentence）翻译句子
其他部分题型有特定字段，表单会自动显示
💡

不确定该用哪个？「认识新词」适合讲新词，「翻译/填空」适合练习，「阅读」类适合段落。也可以用 AI 生成，它会自动选题型（见 §5）。

4.4 资源库（词汇 / 表达 / 语法点）

点顶部 「资源」→「本地资源」，打开三个表格标签页：

  • 词汇表（vocab）：每个词一行，字段 id / term(原文) / translation(译文) / pronunciation / tags。
  • 常用表达（expressions）：短语/短句，字段同上。
  • 语法点（grammar_points）：id / title / explanation / 例句引用。

操作：

  • 直接双击单元格编辑，改完点「保存」。
  • CSV 导入/导出：点标签页里的按钮，可以批量从 Excel 导出的 CSV 增补词汇（适合一次性导几百个词）。
  • Git 资源库：点「资源」→「Git 资源库」，可以连接一个远程 Git 课程仓库，clone 下来、改完 push 回去，或把里面的课程复制到本应用。
⚠️

资源的 id 是不可改的（课时靠 id 引用它们，改了会断链）。新增时程序会自动生成 id。

4.5 发布

课程改完，点顶部 「发布」，弹出发布清单：

  1. 本次改动：列出哪些文件变了（索引、sections、资源等）。
  2. 版本号变更：程序会建议给 index.json 的 version 加 1，你可以取消勾选某个文件的升级。
  3. 音频资源核对：列出课时引用的音频文件是否齐全（缺的会标红）。
  4. 校验状态：显示 validate + lint 是否通过。
  5. 点 「确认发布」：应用版本号升级 + 保存（保存时再跑一次校验，失败会回滚）。
ℹ️

发布不会把课程装到手机。它只是给课程打个版本号、确认无误。装到手机要走 Flutter 打包。

4.6 设置

点顶部 「设置」，左边一列分类：

分类能调什么
外观深色/浅色主题；UI 字体缩放 80%–150%
AI 配置选 AI 供应商（DeepSeek/OpenAI/Moonshot/Ollama/自定义），填 Base URL / API Key / Model；调超时、温度、重试次数；「测试连接」发 1 个 token 验证
AI 用量今日/累计 token、请求数、估算成本、成功率；可清空本地记录
编辑器自动保存开关；撤销步数上限（10–500）；最近仓库历史
操作日志本次会话所有操作记录，可按类型过滤
🔐

API Key 安全：只在当前会话内存里，关闭编辑器自动清空，不写磁盘。Base URL / Model 等会持久化。AI 配置全应用共用一份，不用每个对话框都重填。

5AI 功能：课程工坊

⚠️

所有 AI 功能都消耗 token（花钱或花额度），且输出仅供参考，必须自己审核。

底部状态栏常驻提示：「AI 生成内容仅供参考，请作者自行审核其准确性与适用性。」

「课程工坊」是唯一的 AI 入口（工具栏按钮，非模态窗口，可以和主窗口同时开着）。

  1. 项目库：选「从教材新建…」或「空白 AI 项目」。
  2. 创意画布（选项目后）：左边管教材/知识点/气泡，中间是 AI 轨道（填主题点生成）， 右边默认「结构大纲」（试做/导入），高级用户才打开「设计与草稿」看 JSON。
  3. 头栏 checklist：素材 · 知识 · 草稿 · 导入。随时可关窗续作；Esc 可取消进行中的任务。

5.1 先配好 AI

第一次用 AI 前，去 「设置 → AI 配置」：

  1. 供应商预设：下拉选一个，会自动填好 Base URL 和默认模型。国内常用 DeepSeek。
  2. API Key：去对应供应商官网申请，粘贴进来（关闭程序就清空，下次要重填）。
  3. Model：一般用默认即可，也可手填。
  4. 测试连接：点一下，几秒内告诉你能不能连通。连通了才能用 AI。
💡

没配好就点 AI 功能？会提示「请先在设置中配置 AI API」。去配好再回来。

5.2 两种项目

你的情况点哪个之后
已有一本电子教材从教材新建…进入画布，左栏从教材做起（§5.3）
从零生成空白 AI 项目进入画布，中间填主题即可（§5.4）

5.3 教材项目：从教材到课程

适合：你已经有一本电子教材（Markdown、文本可选中的 PDF）。

📖

详细说明见 textbook-import.md。

  1. 左 · 教材与章节：拖入文件，勾选章节，选教材类型与并发数。
    ⚠️ PDF 必须是文字可选中的。
  2. 左 · 知识点审校：提取词汇/表达/语法点；可 AI 修复、重试/仅抽词汇/跳过。
  3. 中 · AI 轨道：可把气泡拖入聚焦；填主题后点圆形 「AI 核心」 或 Ctrl+Enter。
  4. 右 · 结构大纲：试做、diff、AI 修复；点 「导入到课程 ↗」。
    策略什么时候用
    合并预览（默认）重新导入同一教材、想保留已有改动
    跳过已存在只想补新章节
    覆盖已存在确定要替换旧内容
    作为新 section 追加想新旧并存（自动改 id）
  5. 记得点主窗口「保存」。可「定位到课程树」或按提示切换教师模式。

5.4 空白项目 / 和 AI 一起编课

适合：从零快速生成，或需求还不明确想和 AI 聊着磨合。

  1. 中间填主题、等级、单元/课时、模板。
  2. 需要细聊：点「打开对话 / 附件 / 模板…」，可拖附件。
  3. 点 「AI 核心」 或 Ctrl+Enter 生成（Esc 可确认后取消）。
  4. 右栏结构大纲里试做 → 导入到课程 → 主窗口保存。
💡

教材项目 AI 优先从知识点选词；空白项目自由发挥。花费见「设置 → AI 用量」。

7常见问题（FAQ）

启动报错 No module named PySide6？

没装图形库。回到 §2.1 运行 pip install PySide6。

保存时弹了一堆错误？

课程有结构问题（比如课时引用了不存在的词）。程序会自动回滚，你的改动没丢。按弹窗里的提示改对再保存。常见原因：删了一个词但还有课时在用它——先把课时的引用改掉再删词。

AI 生成的内容有错怎么办？

AI 输出仅供参考。在 JSON 编辑器里手动改，或对错误行点「AI 修复」让 AI 自动修，改完再导入。导入后一定自己再过一遍。

导入教材时 PDF 提示「未提取到文本」？

多半是扫描版 PDF（图片）。用别的工具（如 OCR）把它转成 .md 或 .txt 再导入。

导入教材某章一直失败？

课程工坊左栏「知识点审校」里对该章选「重试本章」；还失败选「仅抽词汇」；或「跳过本章」。

不想每次都填 API Key？

API Key 出于安全只在内存，关程序就清空，这是设计如此。Base URL / Model 会记住。

改错了想回到刚才的状态？

Ctrl+Z 撤销，可连按多次。撤销步数在「设置 → 编辑器」里调。

课程做完了怎么装到手机？

GUI 只负责编辑课程 JSON。装到手机要走 Flutter 打包流程（flutter build apk 等），不在本指南范围。

自动保存会不会误存？

自动保存只在关闭窗口且有未存改动时触发（可在设置关）。平时要存盘还是得点「保存」。

8名词解释

词通俗解释
Section课程的大阶段，对应一个难度等级（如 A1 入门、B1 中级）
Unit单元，一个 Section 里有几个 Unit
Lesson课时，一个 Unit 里有几节课，学生一节节学
stage / sub-lesson课时内部的细分：一节课可有多个子课，每个子课有多个阶段
vocab / expressions / grammar_points三类资源库：词汇、常用表达、语法点。课时里靠 id 引用它们
id每个资源的唯一编号，不可改（改了会断链）。新增时自动生成
validate / lint校验：validate 查结构错误（必报），lint 查内容质量（告警）
tokenAI 计费单位，大概 1 个汉字≈1–2 token。生成课程会消耗几千到几万 token
JSON课程文件的存储格式，纯文本，GUI 帮你编辑，不用手写
prerequisite前置依赖：学这节课前要先学过哪节
Beta功能还在测试阶段，可能有 bug，输出需仔细审核
📌

一句话总结：打开课程 → 左边选节点 → 右边编辑 → 保存（自动校验）→ 满意了发布。

AI 能帮你起稿，但最终要你自己把关。遇到不确定的，先存盘，再撤销，不会丢东西。
