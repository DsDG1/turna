## 使用规则

1. 主题先收窄成学习者能完成的真实任务，再写词表和题目；不把主题列表当语法目录。
2. 每章沿用引入、练习、对话、听力、阅读、开口和测试的螺旋结构；前置章内容必须复现。
3. 来源、作者、土耳其语/中文审校和媒体许可随实际内容补齐；没有审校记录的内容保持候选状态。
4. 官方大纲提供主题和能力参照，不替代真实初学者反馈，也不证明课程已经对齐全部级别标准。
