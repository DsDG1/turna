# Turna 项目框架分析（产品 / 用户视角）

> 本文档从**产品经理、用户研究员和潜在运营者**的视角，关注产品定位、用户体验闭环、商业化边界与风险。**架构 / 功能 / 实现的工程细节见 [`docs/project-guide.md`](../project-guide.md)**，本文不重复。
>
> 更新：2026-08-07。

---

## 1. 一句话定位

Turna 是一款**本地优先、离线可用、类 Duolingo 体验的语言学习框架**，当前以土耳其语为默认目标语言，强调：

- 无账号、无社交、无内购的**纯净学习体验**；
- 由课程树、FSRS 复习、错题/弱词回顾、每日提醒、成就与装饰系统构成的**完整学习闭环**；
- 基于 JSON 课程内容的**可扩展多语言框架**，并打通 Anki 牌组导入与统一 AI 引擎层。

---

## 2. 目标用户与使用场景

| 维度 | 描述 |
|------|------|
| **核心用户** | 希望自学土耳其语（或后续扩展语言）的成人/青年学习者，偏好无干扰、离线可用的移动学习。 |
| **使用场景** | 通勤、睡前 10–15 分钟碎片化学习；以连续打卡（Streak）和成就/装饰系统维持动力。 |
| **用户痛点** | 不想注册账号、反感广告/内购/体力系统、需要听力输入与错题复习、希望导入自有 Anki 牌组。 |
| **价值主张** | "打开即学，学完即走，离线也能保持学习进度；可导入 Anki 牌组、由 AI 辅助生成内容。" |

## 3. 用户体验闭环

### 3.1 启动

1. **Splash**：品牌露出，检测 TTS 可用性（土耳其语语音包缺失时引导安装）。
2. **主界面初始化**：检查连续打卡、同步宝石/成就、内容版本升级时提示重置进度。
3. 进入 **Learn Tab**，课程树加载当前章节。

### 3.2 学习

```
选择课程 -> 逐题作答 -> 正确：升级音效 + 下一题
                    -> 错误：错误音效 + 记录错题 + "Got It"
     ↓
完成课程 -> 结算（XP / 宝石 / Perfect）-> 更新课程树状态
     -> 发放 XP（含 Perfect 加成）/ 宝石、记录完成、检查成就、写学习日志
```

### 3.3 复习

- 单词/表达首次出现即进 SRS 队列；按 FSRS 复习（目标保持率 0.9），失败走当日重学阶梯；
- 错题经 My Mistakes 与 Weak Words 两条路径重练；
- Anki 牌组导入后，到期卡走保真复习（Show Answer -> Again/Hard/Good/Easy）。

### 3.4 持续动力

| 机制 | 说明 |
|------|------|
| **XP** | 课程完成 + Perfect 加成；SRS / Grammar Review 每次奖励。 |
| **Streak** | 每日首次学习延长；断签归零。 |
| **Gems** | 完成 / Perfect / 成就奖励；可兑换头像环装饰（`GemsProvider.spendGems`），**不可购买**。 |
| **Perfect 课程** | 全对标记，课程树显示。 |
| **课程树徽章** | 已完成 / 到期复习 / 薄弱。 |
| **本地每日提醒** | 固定时间通知，无 streak repair。 |

## 4. 产品化边界与决策取舍

### 4.1 已明确移除（vs Duolingo 主动做减法）

- ❌ 账号 / 登录 / 云同步
- ❌ 排行榜、联赛、好友、社交成就
- ❌ 体力 / 生命值
- ❌ 内购、宝石购买、付费道具
- ❌ 连签修复、周末护符
- ❌ 推送通知（仅本地提醒）
- ❌ 语音识别 / 口语评分（TTS 替代）

> 宝石可消耗于纯装饰头像环，但无付费入口，保持无摩擦。功能实现状态见 project-guide §4 / §15。

### 4.2 取舍的产品意义

- **优势**：体验纯粹、无付费压力、留存不依赖 FOMO；适合教育公益、家长放心、隐私敏感用户。
- **劣势**：缺社交激励、无订阅变现、无法跨设备同步、对"成就驱动型"用户吸引力不足。

### 4.3 商业化可能性

当前无内购 / 广告 / 订阅，形态接近开源 / 公益教育工具或内容分发框架。若商业化需新增：云同步 + 账号、付费课程包 / 订阅、家庭 / 教师账户，或保持免费通过课程授权 / 内容合作变现。

## 5. 风险与改进建议

### 5.1 当前风险

| 风险 | 说明 |
|------|------|
| **TTS 依赖系统语音包** | 土耳其语语音包未装时 splash 引导安装，可能劝退。 |
| **无跨设备同步** | 换机 / 重装进度丢失（可手动导出 / 导入 JSON）。 |
| **Anki 保真平台差异** | WebView 保真仅 Android/iOS；HarmonyOS / Web / 桌面文本兜底。 |
| **AI 依赖外部 key** | AI 功能需用户自配 API key；未配置时不可用。 |

### 5.2 改进方向

1. **内容深化**：8 节已有真实内容，后续按语料词频与 CEFR 语法渐进扩充。
2. **Anki 二期**：review-ops、per-deck stats / browser / export、`{{type:}}` 输入桥、OHOS import sqlite3 FFI。
3. **数据导出 / 导入体验**：强化备份与跨设备迁移易用性。
4. **多语言入口**：语言选择页 + "更多课程即将到来"。
5. **教师 / 班级模式**：学习统计 + 错题数据导出报告。

---

## 6. 结论

Turna 已构建成熟、可扩展、测试充分、产品边界清晰的语言学习框架，在 FSRS 复习、Anki 集成、统一 AI 引擎三个方向持续深化。它在"类 Duolingo 体验"与"去商业化、离线、隐私优先"之间明确取舍，适合作为教育公益应用、内容分发平台、或后续商业化的产品基础。后续重心从工程框架建设转向内容深化、Anki / AI 打磨与用户增长。
