# Turna 使用指南

Turna 是一款离线优先的语言学习框架,目前以土耳其语为主要目标语言。
本指南按"上手 → 上道 → 进阶"3 步走,8 节重点说明应用能做什么、为什么这么做。

---

## 1. 课程结构

应用把内容拆成 3 层:Version → Section → Unit → Lesson → Stage。

- Section(章节):8 个 CEFR 等级(A1→B2),按区间前置依赖连成学习路径,
  解锁前需要先完成上一章节。
- Unit(单元):章节下的若干主题分组,例如"问候语" / "数字" / "家庭"。
- Lesson(课):一次学习的最小单位,通常包含 5–15 张互动卡片。
- Stage(阶段):课内的具体步骤,例如 vocab → expression → grammar → reading。

> 第 1 章问候语单元已填充真实内容(8 词 + 2 表达),其余章节仍为占位
> 等内容补全。

---

## 2. 6 种课型模板

每个 Lesson 都有一种课型,它决定 Stage 顺序和题型的搭配:

- intro:新概念引入,词汇 + 朗读 + 简单选择。
- practice:基础练习,搭配选择 + 翻译 + 填空。
- listening:听力训练,TTS 朗读后选择 / 拼写。
- reading:阅读题,短文 + 判断 / 选择 / 简答。
- review:综合复习,把本章节学过的词再来一波。
- mastery:通过线 80%,再做错题会回到 review 卡。

Lesson 标题旁的徽章会显示课型,学习前先看一眼能预估要做多久。

---

## 3. 间隔重复(SRS):为什么单词会"自动回来"

Turna 不强制每天背多少词,而是用间隔重复算法在合适的时刻召回你快忘的词。

- SM-2(教学版):老牌算法,按"难 / 较难 / 较易 / 易"4 档评分。
- FSRS(1.1.0 引入):连续记忆模型,本地学习你的记忆曲线。
  记忆参数保存在本机,不上传。
- 每次复习后算法会算出"下次最可能遗忘"的时间,App 就把那张卡放回 SRS 队列。

> 你不需要记"今天要复习哪些词",只要打开 App 看到 SRS 队列,看到几张
> 就复习几张。复习过后,App 自动安排下一次。

---

## 4. 错题本与弱词复习

- 错题本:每次答错都会被记录,带时间戳。
- 弱词复习:根据最近 30 天错题和错题次数(≥ 2),自动挑出 10 个最需要
  强化的词,组成一个小测验。
- 在 `Play` Tab 可以找到"错题"和"弱词"入口。

---

## 5. 隐私与离线

- 无云端账号:不上传任何学习记录;卸载即清空。
- 无推送:不接入任何推送服务,本地每日提醒是单独设置的闹钟,不会
  触发网络调用。
- 课程内容打包:课程 JSON 随 App 一起打包,首次启动后从
  `assets/courses/` 载入 SQLite。
- 导出 / 导入:设置 → 数据 → 导出,会生成一份 JSON 备份;切换设备
  或重装后可导入恢复。

---

## 6. 主题与可访问性

- 主题:亮色 / 暗色 / 跟随系统三档,持久化保存。
- 字体大小:全文缩放。
- 减弱动效:关闭卡片转换动画。
- 高对比度:为弱视用户准备的对比度增强。
- 阅读障碍友好字体:开启后正文切换为 OpenDyslexic 风格字体。
- 专注模式:屏蔽学习以外的所有弹窗。

设置项在 `设置 → 显示 / 主题`。

---

## 7. AI 助手

- 课内 AI 提示:卡住时可点"?"按钮,给你一些引导性提示而不是直接答案。
- AI 课程设计器:用自然语言描述需求,生成完整的 Lesson 草稿,审核后
  才能落地。
- AI 教材导入:外语文本(markdown / PDF / Word)→ 自动切分 → 知识合并
  → 预览 → 入库。
- API 密钥:所有 AI 调用走你自己的 API 密钥,设置 → AI 中心配置。
  支持 DeepSeek / OpenAI / 自定义兼容 OpenAI 的端点。

---

## 8. 键盘 / 触摸快捷键

- 顶部 Tab 切换:在 `学习 / 练习 / 我的` 三个底部 Tab 滑动或点击。
- 答题:选项点击 / 数字键 1–4 / 上下左右切换。
- 跳过 / 退出:右上角 X 二次确认后退出当前 Lesson。
- 复制内容:更新日志 Tab 右上角 `📋` 一键复制整页。

> 词卡上的喇叭图标可以复读,长按可暂停 / 取消朗读。
